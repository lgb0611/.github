## 2. 색상 — 색은 “의미”로 고름

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `bg` | `#F3F6FB` | 페이지 바탕 (옅은 회청색) |
| `surface` | `#FFFFFF` | 카드·차트 바탕 |
| `surface2` | `#EAF0F7` | 표 머리글, 버튼, 강조 칸 |
| `inset` | `#F5F8FC` | 카드 안의 안쪽 상자(callout, 주의 상자) |
| `line` | `#CCD7E5` | 테두리, 차트 격자선 |
| `text` | `#15263F` | 제목, 굵은 글씨 |
| `soft` | `#293B52` | 본문 글씨 |
| `muted` | `#52657D` | 부제, 출처, 축 글씨, **배경 데이터(미검토·기준값)** |
| **`cyan`** | `#007589` | **주인공** — 핵심 수치, 주 계열, 링크, 섹션 번호 (진한 청록) |
| **`amber`** | `#A65400` | **비교 대상**, 기준선(1배 점선), 주의 상자, 시나리오 영역 (진한 주황) |
| **`red`** | `#C0344E` | 하락 캔들, 음의 수익률, 대안(나쁜) 시나리오, 저항 구간 |
| **`green`** | `#14734E` | 상승 캔들, 양의 수익률, 신규/추가 관찰, **좋은 방향의 감소** |
| `purple` | `#7155B7` | “조건부” 태그에만 |
| `note-bg` | `#FFF5E8` | 범위 공개 상자 바탕 |
| `row-hl` | `#E7F3F6` | 표 강조 행 |

기준 파일: `SK하이닉스 — 정량 소각이 만드는 2030년 주가` 보고서의 밝은 색 테마. (처음 버전은 Meta Muse 보고서의 어두운 남색 테마였음 — 필요하면 git 기록에서 되살릴 수 있음.)

차트 색은 `:root`의 CSS 토큰에서 자동으로 읽음(`getComputedStyle`). **색을 바꿀 때는 `:root` 한 곳만 고치면** 차트까지 같이 바뀜. 옅은 영역은 `tint(C.red,.06)`처럼 토큰 색에 투명도를 줌.

색 고르는 순서:
1. 주인공 한 개만 청록. 나머지는 회색(`muted`)으로 물러나게 함.
2. 두 대상을 비교하면 **청록 vs 호박색**.
3. 좋다/나쁘다를 말할 때만 초록/빨강. **부호가 아니라 의미를 따름** — 비용이 −25% 줄었으면 음수라도 초록.
4. 연한 영역 칠하기는 같은 색을 투명하게: 저항 `tint(C.red,.06)`, 지지 `tint(C.green,.06)`, 시나리오 `tint(C.amber,.06)`.

색각이상 검사 결과(원본 팔레트 그대로 검사함):
- 청록과 초록은 서로 비슷하게 보이고, 초록과 주황은 적록색약에게 헷갈릴 수 있음.
- 그래서 **두 색이 한 차트에서 서로 다른 분류를 뜻할 때는 반드시 모양도 다르게**(원 / 빈 원 / 네모 / 마름모) 하고 이름표를 붙임.
- 원본 산점도는 ‘직접 연결’과 ‘구조적 노출’이 둘 다 같은 청록 원이었음 → 템플릿에서는 ‘구조적 노출’을 **빈 원**으로 바꿔 구분함.

## 3. 페이지 뼈대 (위에서 아래로)

1. **머리글** — 왼쪽 브랜드 `나쁜양파 · Bad Onion`(청록), 오른쪽 스터디 이름·날짜·시간대
2. **큰 제목 2줄** — 1줄: 주제, 2줄(`<br><span>`): 관점/부제
3. **소개 문단(dek)** — 무엇을 분석했고 어떤 순서로 판단했는지 한 문단
4. **요약 상자(hero-grid)** — 왼쪽 넓은 칸: 큰 숫자 4개 / 오른쪽 좁은 칸: 결론(굵은 첫 문장)
5. **메타 노트** — `작성일 ≠ 시세 기준일`처럼 오해하기 쉬운 점을 굵게
6. **고정 목차(nav)** — 스크롤해도 위에 붙어 있음
7. **번호 섹션** — `01`, `02`… 청록 번호 + 제목(한 문장 주장) + 부제(범위·기간)
8. **방법·출처 섹션** — 계산식, 데이터 등급, 출처 목록(번호 달린 각주)
9. **바닥글** — 면책 문구를 `≠`로: “시장 반응 ≠ 신규 수주 · 조건부 경로 ≠ 수익률 예측”

## 4. 차트 카드 — 모든 차트는 이 순서

```
┌ 제목(h3)   : 결론을 말하는 문장     예) "초기 다운로드는 출시 16일 안에 3M대를 넘김"
│ 부제(.sub) : 무엇 · 단위 · 기간 · 등급  예) "누적 다운로드 · 백만 건 · Estimate"
│ [차트]
│ ─────────── (가는 선)
│ 해설(figcaption): **첫 문장 굵게 = 핵심 숫자**. 이어서 해석. 마지막에 한계.
│ 주의(.chart-note): 오해 방지 한 줄 (선택)
└ 출처(.source): 기관 날짜 · 등급
```

- 차트 두 개를 나란히 둘 때는 `.two` (모바일에서는 위아래).
- 차트 제목에 “그래프”, “추이” 같은 설명어 대신 **읽는 사람이 가져갈 결론**을 씀.

## 5. 차트 종류별 레시피 (template.html 안의 함수 이름)

| 데이터가 하는 일 | 함수 | 모양 규칙 |
|---|---|---|
| 점 몇 개의 변화 | `lineChart` | 청록 3px 선 + 8px 점, 세로축 0부터, 범례 없음 |
| 항목 2~6개 크기 비교 | `barChart` | 막대 위에 값 글씨(`+55%`, `7 GW`), 위아래 20% 여유, 범례 없음, 긴 이름은 `<br>`로 줄바꿈 |
| 두 그룹 나란히 비교 | `groupedBar` | 청록(주인공) vs 호박(비교), 기준 점선(예: 1배), 값은 `1.83×` |
| 순위 (상위 N개) | `rankBar` | 가로 막대, 1위가 맨 위, 색은 분류, 값 `+29.11%` 막대 끝 |
| 두 지표의 관계 + 분류 | `quadrantScatter` | x=수익률, y=거래량 배수(로그 눈금 `0.5× 1× 2× 5×`), 기준선 x=0(회색 점선)·y=1(호박 점선), 배경 종목은 작고 흐린 회색, 주요 종목만 이름표, 모바일에서 이름표 숨김 |
| 주가 흐름 | `candleChart` | 위 70% 캔들(초록 상승/빨강 하락) + 아래 19% 거래량(같은 색, 50% 투명). 주말 빈칸 없이 **거래일 번호**로 x축. SMA20(호박)/SMA50(회색) 수평 점선 + 오른쪽 이름표, 저항(빨강)/지지(초록) 옅은 띠, 이벤트일 세로 점선. 마지막 봉 오른쪽은 호박색 옅은 영역에 **조건부 경로**(기본=청록 파선, 대안=빨강 점선, 마름모 점) |

공통 모양(`plotLayout`): 카드와 같은 바탕색, 격자선 `line` 색, 글씨 11px, 범례는 위쪽 가로, 마우스 설명(hover) 바탕은 `bg` 색, 내보내기 버튼은 PNG 2배 해상도.

마우스 설명(hover)에는 항상 **등급을 같이** 씀: `9/24 집계<br>3.4M · 외부 추정`, `시나리오 참조 가격<br>실제 미래 체결값 아님`.

## 7. 기업 분석 카드 (순서 고정)

1. 머리: `티커` + 회사명(회색) + 태그들 / 오른쪽 위에 구간 수익률·거래량 배수
2. **투자 논지** 한 문장 (18px 굵게)
3. `무슨 회사인가` (청록 작은 대문자 라벨) + 1~2문단 — 헷갈리기 쉬운 점까지
4. 매출 연결 사슬 3칸
5. 2단 비교: “경쟁사 B보다 앞서는 논거” | “경쟁사 C보다 앞서는 논거” (청록 소제목)
6. 주의 상자 (호박)
7. 분석 상태 한 줄 (회색 작은 글씨: “공급관계 확인 · 산업 분석을 적용”)
8. 본주 캔들 차트 + 수치 배지 + [원자료 보기] [CSV] 버튼 + 해설 + 출처

## 8. 표

- 숫자 칸은 오른쪽 정렬, 첫 칸(종목)만 왼쪽. 머리글은 스크롤해도 고정.
- 종목 칸: 작은 회색 순위 → 굵은 티커 → 작은 회색 회사명 (세 줄).
- 양수 초록 / 음수 빨강, 1배 초과 거래량도 초록.
- 핵심 종목 행은 옅은 청록 바탕(`.row-hl`).
- 정렬·보기·검색 필터는 표 바로 위 한 줄. CSV 저장 버튼 제공(엑셀 한글 깨짐 방지 BOM 포함).
- 결과 없음: “현재 조건에 맞는 종목이 없음.”

## 9. 글쓰기 규칙

- **개조식 명사형**: “상승했음”, “해석함”, “검증된 것은 아님”.
- **주장 먼저, 근거 다음, 한계 마지막.** 한계 문장 예: “이는 모든 CPU 작업에서 우위가 검증됐다는 뜻은 아님.”
- **사실과 해석을 분리**: 공식 사실 / 외부 추정 / 회사 주장 / 작성자 해석을 섞지 않고 표시.
- **숫자 표기**: 수익률 `+12.65%`(부호 항상), 배수 `1.39×`, 감소 `−20%`(유니코드 마이너스), 큰 수 `3.4M`, 시총 `512.3조원`.
- **날짜**: 본문 `9/18 → 9/25`, 표·축 `2026-09-25` 또는 `09/25`.
- **전문용어**는 처음 한 번 괄호로 풀이: `KV cache(이전 문맥 계산을 재사용하는 저장 공간)`.
- **본문 속 출처 링크**: 문장 끝에 작은 청록 `[출처명]` → 아래 출처 목록 번호로 이동.
- **등급 단어**: Actual(관측) · Calculated(계산) · Estimate(외부 추정) · Company claim(회사 주장) · Forecast(전망) · Scenario(조건부 작도).
- **≠ 문구**로 오해 차단: “작성일 ≠ 시세 기준일”, “시장 반응 ≠ 신규 수주”.

## 10. 데이터 정직성 규칙 (원본이 특히 공들인 부분)

- 없는 값을 0이나 추정으로 채우지 않음 → `—` 또는 “확인 중”.
- 자료를 못 구한 대상을 “조건 미달”로 처리하지 않고 따로 공개.
- 주말·휴장일에 빈 봉이나 0 거래량을 넣지 않음 (x축은 실제 거래일 번호).
- 서로 다른 공급자의 분자·분모를 섞지 않음.
- 조건부 경로는 “날짜/시점 미지정 · 실제 미래 체결값 아님”으로 표시.
- 차트용 원자료를 [원자료 보기] 팝업과 CSV 버튼으로 제공.

## 11. 인쇄 · 공유

- 인쇄(PDF 저장)는 A4 세로, 목차·버튼 숨김, 바탕색 유지.
- 텔레그램 등으로 **파일 하나만** 보낼 때: `python make_offline.py 보고서.html` → 차트 라이브러리가 들어간 `보고서_offline.html` 생성(인터넷 없이 열림, 약 5MB 증가).
