# Astra Speaking Lab 2.11.1 — 끊긴 문장 잇기 · DeepL 한국어 번역 · 말하면 받아쓰기

## 이번 변경 (2.11.1): 중간에 끊긴 유튜브 문장 잇기

자막을 문장으로 묶을 때 40단어·45초가 넘으면 문장이 끝나지 않았어도 끊겨서, 뒷부분(`and want to be a part of…`)이 따로 카드가 되고 번역도 어색해지는 문제가 있었습니다. 이제 문장부호가 있는 자막이면, 끊긴 조각을 그 문장을 끝내는 다음 조각과 이어 붙입니다(최대 90단어, 3초 이상 쉰 곳·[Music] 같은 표시는 넘지 않음). 문장부호가 없는 자동 자막은 이전처럼 약 35단어 단위로 나눕니다.

이미 저장한 영상은 다시 열면 새 규칙으로 카드를 다시 만듭니다. 예전 조각 카드 중 복습·연습 기록이 없는 것만 정리하고, 기록이 있는 조각은 복습 목록에 그대로 남깁니다. 이어 붙인 문장은 새 카드라서 한국어 뜻을 다시 준비합니다(DeepL을 연결했다면 DeepL로).

## 2.11.0 변경: DeepL로 더 정확한 한국어 뜻

⚙ 설정 → **한국어 번역 품질 · DeepL 연결**에 DeepL API Free 키(무료 한도 안에서)를 넣으면, 유튜브 문장의 한국어 뜻을 DeepL로 먼저 번역합니다. 이미 번역된 문장은 유튜브 학습 화면의 **DeepL로 한국어 다시 번역** 버튼으로 한 번에 바꿀 수 있습니다. 키는 이 PC의 로컬 실행기에만 보관하고 영어 문장만 DeepL로 전송합니다. 자세한 안내: `docs/DEEPL_KO.md`.

스피킹 연습 화면에서 ‘상황 키워드만 보기’, ‘여러 문장으로 한글 문단 연습’, ‘같은 표현, 다른 상황’, ‘가리고 말하기’ 버튼은 숨겼습니다 (2.10.1).

## 2.10.0 변경: 말한 영어를 바로 글자로

**스피킹 연습**의 녹음 칸에서 **말하는 동안 영어로 받아쓰기**를 켜고 녹음하세요. 말하는 동안 영어가 실시간으로 나타나고, 녹음을 마치면 **내가 실제로 말한 문장** 입력란에 들어갑니다. 더 이상 직접 타이핑하거나 Windows 받아쓰기를 따로 켤 필요가 없습니다.

**말한 답변 자가 점검**을 누르면 예시 답안에 표시가 붙습니다.

- 초록은 내 답에도 있는 단어, 주황은 내 답에 없던 단어입니다. "예시 답안 단어 N개 중 M개를 같은 순서로 말했어요"도 함께 보여 줍니다.
- **목표 표현 찾기**는 `came up with`(→ come up with), `asked her out`(→ ask someone out)처럼 시제나 자리표시어가 달라도 찾아 줍니다.
- 단어 비교는 점수가 아닙니다. 같은 뜻을 다른 말로 했다면 주황이어도 괜찮습니다. 복습 평가는 이전처럼 직접 고릅니다.

받아쓰기는 **기본으로 꺼져 있습니다.** 켜면 녹음하는 동안 말소리가 브라우저의 음성 인식 서비스(Chrome은 Google, Edge는 Microsoft)로 전송됩니다. 요금은 없고 앱의 유료 API도 쓰지 않습니다. 인식이 틀릴 수 있으니 녹음을 들으며 고친 뒤 확인란을 체크하세요. 받아쓰기가 멈춰도 녹음은 계속됩니다. Firefox처럼 음성 인식이 없는 브라우저에서는 체크박스가 비활성화됩니다.

자세한 안내와 검증 범위: `docs/DICTATION_KO.md`. 이전 2.9.0 설명서는 `docs/v2_9_archive/`에 있습니다.

## 2.9.0 변경: 전체 문장으로 시작하기

`유튜브 듣고 말하기`에서 링크를 넣고 **이 영상으로 자동 학습 만들기**를 누르세요. 영어 자막을 불러오면 마지막 문장까지 한 번에 학습 카드로 만듭니다. 추출 개수 선택과 ‘다음 문장 추가’는 없어졌습니다. 자막 붙여넣기·파일 가져오기도 전체 문장을 처리합니다.

짧은 답변과 반복해서 등장하는 문장도 원래 순서대로 포함하며, 음악·박수 같은 비발화 표시만 제외합니다. 자막에 문장부호가 없으면 원문을 긴 발화 청크로 묶으며, 없는 문장이나 시간을 만들지 않습니다.

화면에는 처음 10개를 보여 줍니다. **추출된 문장 더 보기**는 이미 준비된 목록을 펼치는 버튼입니다. 전체 문장 듣기·구간 반복·한글 보고 한 문장씩 말하기는 처음부터 전체 목록을 사용합니다. 한국어 뜻은 순서대로 준비하며, 준비를 중단해도 추출된 문장과 완료된 번역은 남습니다.

예전 버전에서 일부만 추출한 현재 영상은 같은 브라우저에 전체 자막 초안이 남아 있으면 다시 열 때 자동으로 나머지를 채웁니다. 기존 카드 ID·번역·복습 기록·진행 중인 연습 순서는 유지합니다. 자막이 남아 있지 않은 다른 영상은 해당 자료의 **자막·대본 열기**를 눌러 불러오세요.


학습 자료 탭에서 기본 26개 자료와 이 브라우저에 저장한 유튜브 자료를 모두 찾아 공부할 수 있습니다. 기본 자료의 3,381개 학습 항목과 원본 파일 35개를 그대로 포함합니다. 앱은 무료 모드로 시작합니다.

## 시작하기

1. 기존 실행 창을 종료하고 새 ZIP을 모두 압축 해제하세요.
2. 새 폴더의 `start_youtube_windows.bat`을 실행하세요.
3. 기존에 쓰던 브라우저와 같은 주소를 사용하세요. 기본 주소는 `http://127.0.0.1:8765/`입니다.
4. 상단 **학습 자료**에서 자료를 고르세요.

기존 학습 기록은 브라우저에 저장됩니다. 같은 주소·같은 브라우저 프로필을 쓰면 기존 기록과 저장한 유튜브 문장을 이용합니다. 주소나 브라우저를 바꾸려면 이전 앱의 설정에서 기록을 내보낸 뒤 새 앱에서 가져오세요.

인터넷 연결 없이 포함된 자료를 읽고 공부하려면 `OPEN_ME.html`을 Chrome 또는 Edge로 열어도 됩니다. 다만 이 방식의 저장 공간은 서버 주소로 실행할 때와 다를 수 있습니다. 녹음과 영상 자막 가져오기는 무료 실행기 사용을 권장합니다.

## 자료별로 공부하기

**가브리엘 / KPOP:** `한글 문단으로 말하기`로 준비된 문제를 시작하거나, 해당 자료의 표현을 열어 한 개씩 연습하세요. 한국어 문제를 먼저 보여 주고 영어 예시는 가립니다.

**연설문:** `표현 N개 공부하기`로 그 연설문의 단어·표현·뜻을 확인하세요. `예문 듣기`는 원자료 인용 예문을 읽고, `뜻 보고 문장 말하기`는 그 뜻을 담은 문장을 직접 만들도록 합니다. 연설문 항목 수는 완성 문장 수가 아닙니다. 원본 해설 Word 파일도 함께 제공합니다.

**인터뷰 PDF:** `이 자료로 공부하기`로 문장 학습 화면을 엽니다. 영어 아래 한국어가 처음부터 나오며, 문장 듣기·대본 전체 재생·구간 반복·한글 보고 말하기·2~5개 선택 문단·응용 문단을 사용할 수 있습니다. `전체 학습 자료`로 돌아오면 검색 조건이 유지됩니다. 세 PDF의 한국어 507개와 응용 문단 15개는 미리 들어 있어 번역 연결이 필요 없습니다.

**유튜브:** 처음에는 `이 영상으로 학습 시작`으로 자막을 불러옵니다. 저장한 문장이 있으면 `저장한 문장 공부하기`로 바로 열고, `자막·대본 열기`로 전체 문장 추출과 듣기를 이어갈 수 있습니다. 현재 영상과 다른 자막으로 바꿀 때는 기존 자막 변경을 확인합니다. 저장한 문장만 공부할 때는 다른 영상의 자막 초안을 바꾸지 않습니다.

Arthur Brooks 영상은 제목·채널·길이·영어 자동 자막 트랙만 확인된 항목입니다. 이 ZIP에 새 영상의 대본·한국어 뜻이 미리 들어 있지는 않습니다. 실제 자막을 불러와야 학습 문장을 만들 수 있으며, 자막 본문을 가져오는 성공 여부는 사용자 PC의 네트워크와 영상 접근 상태에 달려 있습니다.

## 듣기와 복습

영어 듣기는 브라우저의 합성 음성을 사용합니다. 영어 음성이 없으면 `목소리 새로 읽기`를 누르거나 Windows에 영어 음성을 추가하세요. 온라인 음성만 있으면 화면에 표시된 **온라인 영어 음성 사용**을 직접 허용해야 재생할 수 있습니다.

말한 뒤 녹음이나 입력한 답변을 확인하고 자가 점검하여 복습 일정을 저장하세요. 받아쓰기를 켜면 말한 영어가 입력란에 자동으로 들어갑니다. API 키 없이 공부할 수 있습니다. 새 영상의 한국어 뜻은 지원되는 브라우저 번역 또는 준비된 무료 로컬 AI를 사용하며 최초 설정·언어 파일 다운로드가 필요할 수 있습니다.
