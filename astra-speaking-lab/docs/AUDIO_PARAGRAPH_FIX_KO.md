# 음성 듣기·문단 선택 수정 — v2.5.1

## 소리가 나지 않았던 이유

이전 버전은 온라인 영어 음성을 기본적으로 사용하지 않게 했는데, 이를 허용하는 체크박스를 스피킹 화면의 접힌 설정 안에 두었습니다. YouTube 학습 화면에서는 사용할 수 있는 온라인 음성이 있어도 ‘사용 가능한 영어 음성 없음’과 위치가 맞지 않는 ‘아래 허용 옵션’ 안내가 나타났습니다. 같은 안내가 재생 상태와 음성 목록 상태에 중복 표시되기도 했습니다.

수정본에서는 **온라인 영어 음성 사용** 체크박스를 카드 위 듣기 설정에 배치했습니다. 이 설정은 기존 음성 설정과 함께 저장·동기화됩니다. 허용 전에는 온라인 음성을 재생하지 않습니다. 듣기를 먼저 눌렀다면 체크 직후 가장 최근에 선택한 문장 하나만 재생합니다. 정지하거나 다른 화면으로 이동하면 이 대기 요청을 취소합니다.

1. 카드 위 **온라인 영어 음성 사용**을 체크합니다.
2. 같은 곳의 **음성 테스트**로 소리를 확인합니다.
3. 원하는 카드의 **음성 듣기 · 이 문장만**을 누릅니다.

온라인 음성에는 인터넷이 필요하고 읽을 문장이 브라우저 음성 서비스로 전송될 수 있습니다. 앱은 음성 합성을 위해 유료 OpenAI API를 호출하지 않습니다. 기기 음성이 있으면 온라인 허용 없이 사용할 수 있습니다. [기기 음성과 원격 음성의 구분](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)

브라우저가 음성 목록을 나중에 제공하면 선택 목록을 갱신합니다. 음성 목록이 실제로 비어 있는 경우와 온라인 음성 허용만 필요한 경우를 구분합니다. [음성 목록](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices), [음성 목록 변경 이벤트](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/voiceschanged_event)

음성 시작을 8초 동안 확인하지 못하면 멈추고 다시 시도할 방법을 표시합니다. 네트워크 오류와 다른 음성 재생 오류도 해당 화면에 보여 줍니다. 실제 스피커 음량·출력 장치·탭 음소거는 앱이 확인할 수 없습니다. **여전히 소리가 없나요?**를 펼쳐 점검하세요.

## 문단에 활용을 체크한 뒤

이전 체크박스는 선택 개수만 바꾸고 위쪽 연습 버튼을 별도로 눌러야 했습니다. 카드 아래로 스크롤하면 시작 버튼을 보지 못해 아무 동작이 없는 것처럼 보일 수 있었습니다.

수정본에서는 체크한 카드가 강조되고 **화면 하단에 선택 개수와 시작 버튼**이 나타납니다.

1. **문단에 활용**으로 2~5개 문장을 고릅니다.
2. 하단 **선택한 N문장으로 문단 연습**을 누릅니다.
3. 준비 진행 상태를 같은 하단 영역에서 확인합니다. 필요하면 **준비 중단**을 누릅니다.
4. 준비가 끝나면 스피킹 화면으로 이동해 한국어 문단을 보여 줍니다. 영어 예시는 가려 둡니다.

한 문장만 골랐을 때는 한 문장 더 선택하라는 안내를 보여 줍니다. 하단의 문장 번호를 누르면 해당 선택을 해제하고, **선택 해제**로 전부 지울 수 있습니다. 여섯 번째 문장은 선택하지 않고 최대 5개라는 안내를 같은 위치에 표시합니다.

한국어 번역과 무료 로컬 AI 준비 방식은 v2.5와 같습니다. 무료 AI가 준비되어 있으면 새로운 상황의 문단을 만들고, 준비되지 않았거나 생성에 실패하면 선택한 학습 문장의 한국어 내용을 이어 말하는 문단을 제공합니다. 번역이 아직 준비되지 않았다면 준비 방법을 안내합니다.

## 검증 범위

온라인 음성만 있는 화면을 재현해, 허용 옵션의 위치·단일 상태 표시·허용 후 정확한 문장 재생·설정 저장·대기 요청 취소를 확인했습니다. 문단 선택의 강조·개수·시작·해제·5개 제한·진행 표시·중단·한국어 문제 화면 이동도 자동 검사했습니다.

음성 합성과 번역·모델은 모의 응답을 사용했습니다. 실제 사용자의 PC에서 소리가 들리는지, 설치된 음성의 발음 품질, 실제 번역·문단 품질은 이 환경에서 확인하지 못했습니다. 자세한 결과는 **validation_results.json**, **audio_fix_node_test_results.txt**에 있습니다.
