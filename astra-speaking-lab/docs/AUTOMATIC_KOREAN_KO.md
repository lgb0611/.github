# 영어 문장 아래 한국어 뜻 자동 표시 — v2.5.2

이전 버전에서는 새 추출 후 번역을 시작했어도 전체 묶음이 끝나야 화면에 반영했습니다. 저장한 영상의 문장들을 다시 열 때는 누락된 번역을 자동으로 재개하지 않아 ‘한국어 준비’ 버튼 안내가 남을 수 있었습니다.

## 바뀐 흐름

- 새 문장 추출: 한국어 번역도 자동으로 시작합니다.
- 번역 진행: 완료한 문장부터 영어 바로 아래에 한국어 뜻을 표시합니다. 영어 카드나 선택 상태를 새로 만들지 않고 뜻 부분만 갱신합니다.
- 저장 영상 다시 열기: 이미 번역된 뜻을 처음부터 보여 주고, 빠진 문장만 자동으로 번역합니다.
- 문장 더 보기: 준비되지 않은 한국어가 있으면 자동으로 재개합니다.
- 일부 실패: 한 문장의 브라우저 번역이 실패해도 뒤 문장들을 계속 처리합니다. 준비된 무료 로컬 AI가 있다면 누락분을 이어서 번역합니다.

별도의 ‘한국어 준비’ 버튼을 누르는 것이 기본 절차가 아닙니다. 번역 중에는 ‘이 문장의 한국어 뜻을 번역하고 있습니다’와 전체 완료 개수를 표시합니다. 연결 실패·중단 상태에만 ‘한국어 번역 다시 시도’ 또는 ‘남은 한국어 이어 번역’ 버튼을 표시합니다.

## 첫 실행의 번역 준비

지원되는 데스크톱 Chrome의 기기 내 번역을 먼저 사용하고, 사용할 수 없으면 준비된 무료 로컬 AI를 사용합니다. 유료 API는 사용하지 않습니다. 처음에는 번역용 언어 파일을 내려받을 수 있습니다.

Chrome 번역기 생성에는 사용자 동작이 필요할 수 있어, 영상 링크 버튼을 누를 때 자막 요청보다 먼저 번역기를 준비하도록 바꿨습니다. 자막을 기다리느라 사용자 동작 조건을 놓치는 문제를 줄입니다. 브라우저 정책이나 지원 여부에 따라 준비가 실패할 수 있으며, 그때는 연결 안내를 표시합니다. [Chrome 번역 API의 최초 준비와 사용자 동작](https://developer.chrome.com/docs/ai/translator-api)

아직 번역 기능이 없는 환경에서 뜻을 만들어 냈다고 표시하지 않습니다. Chrome 번역 또는 무료 로컬 AI를 처음 한 번 준비해야 합니다. 실제 번역에는 시간이 걸릴 수 있고 자막 오류·구어체·문맥에 따라 뜻이 부정확할 수 있습니다.

## 예시 화면의 형태

**When you scroll on social media, are you seeing like your own song?**

SNS를 보다 보면 본인 노래가 나오는 걸 보시나요?

이처럼 영어 밑에 한국어 전체 의미를 표시합니다. 이 예시는 화면 형태를 설명하기 위한 번역이며, 앱은 사용자가 가져온 각 문장을 자동으로 번역합니다.

## 검증

모의 번역기로 한 문장씩 완료되는 상황을 재현해, 전체 작업이 끝나기 전에 뜻이 나타나는지 확인했습니다. 부분 번역이 있는 백업 복원, 엔진 없이 캐시 표시, 문장 더 보기, 지연된 자막 요청 전 번역기 준비, 한 문장 실패 후 다음 문장 번역, 중단·원문 변경 시 결과 거절도 검사했습니다.

실제 PC에서의 Chrome 언어 파일 다운로드·자동 번역 품질·무료 로컬 모델의 출력 품질은 이 환경에서 검증하지 못했습니다. 검사 결과는 **validation_results.json**, **auto_korean_node_test_results.txt**에 있습니다.
