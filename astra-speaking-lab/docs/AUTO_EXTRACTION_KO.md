# 자동 문장 학습 — v2.9.0

영상 전체에서 마지막 문장까지 한 번에 추출하고 한국어 버전을 순서대로 준비합니다. 추출 개수 선택과 다음 문장 추가는 없어졌습니다. 화면의 더 보기는 이미 추출된 문장을 펼치는 기능입니다. 자막의 단어를 임의로 고치지 않으며 구두점 없는 자막은 긴 발화 청크로 표시합니다. 짧은 자료는 실제 문장 수만큼만 준비합니다.

- **음성 듣기 · 이 문장만:** 앱 안에서 해당 문장을 합성 음성으로 읽습니다.
- **한글 보고 한 문장씩 말하기:** 한국어가 먼저 보이고 영어 답안은 가립니다.
- **여러 문장으로 한글 문단 연습:** 선택한 2~5개 문장을 모두 사용합니다. 무료 AI가 있으면 새 상황 문단, 없으면 학습 내용 이어 말하기 문단을 제공합니다.

한국어는 지원 브라우저의 기기 내 번역 또는 준비된 무료 로컬 AI로 자동 생성합니다. 처음에는 번역용 언어 파일을 내려받을 수 있으며, 자동 연결이 실패하면 「한국어 번역 다시 시도」를 누르세요. 두 기능이 모두 준비되지 않으면 실제 번역이 있는 것처럼 표시하지 않습니다. 원문 링크는 접힌 선택 메뉴에 있습니다.

전체 사용법·준비·검증은 [KOREAN_PRACTICE_KO.md](KOREAN_PRACTICE_KO.md)를 참고하세요. 이전 v2.4 안내는 v2_4_archive에 보관합니다.
