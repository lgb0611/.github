# DeepL로 한국어 뜻 개선하기 (2.11.0)

## 왜 필요한가
유튜브 문장의 한국어 뜻은 원래 **Chrome 내장 번역기**(PC 안에서 도는 작은 번역 모델)나 **무료 로컬 AI**로 만들었습니다. 긴 문장이나 "better qualified, better funded" 같은 대비 구조에서 뜻이 틀리는 경우가 많았습니다. DeepL을 연결하면 새 문장은 DeepL로 먼저 번역합니다.

## 연결 방법 (처음 한 번)
1. https://www.deepl.com/pro-api 에서 **DeepL API Free**에 가입합니다. 매달 50만 자까지 무료입니다. 가입할 때 카드 인증이 필요할 수 있습니다(무료 플랜은 요금이 청구되지 않음).
2. DeepL 계정의 **API Keys** 화면에서 키를 복사합니다. 무료 키는 `:fx`로 끝납니다.
3. 앱 오른쪽 위 **⚙ 설정 → 한국어 번역 품질 · DeepL 연결**에 붙여 넣고 **키 확인하고 연결**을 누릅니다.
   - "이 PC에 저장"을 체크하면 프로젝트 폴더의 `.env` 파일에 저장되어 다음 실행에도 연결됩니다.
4. `start_youtube_windows.bat` 또는 `start_free_windows.bat`으로 실행했을 때만 쓸 수 있습니다. `OPEN_ME.html`을 파일로 직접 열면 비활성화됩니다.

## 이미 번역된 문장 바꾸기
유튜브 학습 화면의 **DeepL로 한국어 다시 번역 · N문장** 버튼을 누르면 기존 기계 번역을 DeepL 번역으로 바꿉니다. 복습 기록·카드 순서는 그대로입니다. DeepL이 연결되지 않았을 때는 그 자리에 **번역이 어색하다면 · DeepL 연결** 링크가 보입니다.

## 동작 방식
- 한 번에 25문장씩 요청하고, 앞뒤 2문장을 `context`(번역하지 않고 뜻 파악에만 쓰는 참고 문장, 요금에 포함되지 않음)로 함께 보냅니다.
- 키는 브라우저·학습 기록에 저장하지 않습니다. 로컬 실행기(`deepl_service.py`)만 DeepL에 요청합니다. 영어 문장만 전송됩니다.
- 한도 초과·인터넷 끊김·잘못된 키일 때는 이유를 보여 주고 기존 번역 방법(Chrome 내장 번역 → 무료 로컬 AI)으로 이어서 번역합니다.
- PDF 자료(JENNIE·Elon Musk·Harvard)처럼 미리 넣어 둔 한국어는 바꾸지 않습니다.

## 검증
- Python: 가짜 DeepL 응답으로 번역·키 확인·저장/해제·한도 초과·잘못된 키·형식 오류 8개 테스트 통과.
- 화면: 새 문장 DeepL 번역(25문장 묶음, 앞뒤 문맥), 기존 번역 한 번에 교체(복습 기록 유지), 실패 시 기존 번역기로 전환, 키가 브라우저 기록에 남지 않음, 파일로 열었을 때 비활성화 — 5개 테스트 통과.
- 실제 Chromium에서 가짜 키를 넣었을 때 실제 DeepL 서버가 거절했고, 앱이 "키가 올바르지 않습니다"를 표시하고 키를 저장하지 않았습니다.
- 실제 유효한 키로 번역을 받아 본 것은 아닙니다(이 환경에 키가 없음).
