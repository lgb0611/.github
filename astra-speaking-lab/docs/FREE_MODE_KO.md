# 유료 API 없는 학습 — v2.5

문장 추출·합성 음성 듣기·녹음·자가 점검·복습은 OpenAI API 키 없이 동작합니다. 한국어는 지원 브라우저의 기기 내 번역이나 준비된 로컬 AI로 자동 생성합니다. 처음에는 번역용 언어 파일 또는 로컬 모델 다운로드가 필요할 수 있습니다.

새로운 상황의 한글 문단은 준비된 로컬 AI로 생성합니다. AI가 없거나 생성에 실패하면 학습 문장들의 한국어 내용을 연결한 문단으로 연습합니다. 두 문단의 출처를 화면에 표시합니다. 일반 문장 듣기는 YouTube에 연결하지 않습니다.

자막 불러오기는 YouTube의 공개 자막 접근 여부에 따라 실패할 수 있습니다. 이 경우 스크립트나 TXT/SRT/VTT를 가져옵니다. 음성 합성은 기기 영어 음성이 기본이며 온라인 음성은 설정에서 직접 허용할 때만 사용합니다.

사용법과 검증 결과는 [KOREAN_PRACTICE_KO.md](KOREAN_PRACTICE_KO.md), [validation_results.json](validation_results.json)에 있습니다.
