# 인터뷰 학습 자료 추가 · v2.7

두 PDF를 프로그램에 기본 자료로 포함했습니다. 다시 업로드하거나 자막·표현·뜻을 입력하지 않고 바로 공부할 수 있습니다.

## 포함 범위

| 자료 | 원자료 구성 | 앱의 학습 단위 |
|---|---|---|
| JENNIE INTERVIEW — Practice #20260909 | 4쪽. 표현표 19개, 바로 말하기 15개, 표현 요약, 확장 연습 40개 | 번호가 있는 55개 연습 항목을 전부 수록. 여러 문장인 5개 항목을 나눠 듣기 단위 60개. 반복 등장하는 문장도 원자료 순서대로 유지 |
| Elon Musk Interview | 20쪽, 번호가 있는 39개 주제 | 문장·짧은 응답·상황 설명 363개. 질문과 답변, 마지막 인사까지 순서 유지 |
| 새 상황 말하기 | 앱에서 별도 작성 | 각 자료 5개, 총 10개. 문단당 3~4개의 학습 문장을 사용하고 한글 문제·영어 예시를 연결 |

제니 자료는 인터뷰 표현을 활용한 **연습지**입니다. 예문을 제니의 실제 인터뷰 발언으로 표시하지 않습니다. 2쪽의 한국어는 제공된 내용을 따랐고, 듣기 단위가 나뉜 부분은 문장별로 맞췄습니다. 4쪽 확장 예문의 한국어는 앱에서 작성했습니다. 3쪽 핵심 요약은 표현표와 중복되므로 별도 문장 카드로 중복 집계하지 않았습니다.

일론 머스크 자료의 발화자와 주제 구분은 **사용자가 제공한 PDF 기준**입니다. 32번 주제는 자료의 상황 설명이며, 33·34번 주제의 설명 부분도 직접 발언과 구분했습니다. 시간표에 있는 ‘약 5년’, ‘약 10년’은 해당 문장의 맥락으로 표시합니다. 전망이나 정치적 주장을 외부에서 사실 확인한 대본이라는 뜻은 아닙니다. 출처가 없는 영상 링크나 발화 시간은 붙이지 않았습니다.

영어 원문은 PDF의 줄바꿈과 글꼴 제어문자를 정리했습니다. 일론 머스크 PDF는 일반 텍스트 추출에서 fi/ff 같은 글자가 분리되는 문제가 있어, 해당 글자를 보존하는 추출 결과를 사용했습니다. 열린 따옴표만 남지 않도록 한 응답의 인용문은 함께 유지했습니다.

## 사용 순서

1. 상단 **인터뷰 자료**에서 자료를 고릅니다. 첫 화면의 두 자료 버튼이나 ‘오늘 사용할 자료’에서도 열 수 있습니다.
2. **대본 전체 재생**으로 자료 전체를 듣거나, **공부할 주제 → 선택 주제 듣기**로 작은 단위를 듣습니다.
3. 시작·끝 문장, 반복 횟수, 쉬는 시간을 골라 구간을 반복합니다. 카드의 **이 문장 반복**도 같은 반복 설정을 사용합니다.
4. 영어 아래에 한국어 뜻이 처음부터 표시됩니다. **한글 보고 말하기**를 누르면 스피킹 화면에 한국어만 먼저 제시합니다.
5. 한 번에 **20개 묶음**으로 진행하거나 카드 2~5개를 골라 **선택한 문장으로 한글 문단 말하기**를 시작합니다. 페이지를 넘겨도 최대 5개의 선택은 유지됩니다. 주제를 바꾸면 선택은 초기화됩니다.
6. 다른 상황에서 써 보려면 자료 하단의 **응용 문단** 5개 중 하나를 고릅니다. 문단은 한국어부터 제시하며 영어 예시는 힌트를 열 때 표시합니다.
7. 녹음·자가 점검 후 복습 일정을 저장합니다. 새 자료의 카드와 응용 문단은 기존 학습 기록에 연결됩니다.

카드의 주제 필터·20개 페이지는 문장 학습에만 적용됩니다. **대본 전체 재생**은 항상 선택한 PDF 자료 전체를 읽습니다. 다른 PDF나 유튜브로 이동하면 이전 재생을 중단하며, 기존 유튜브 자막 초안은 유지합니다.

## 무료 학습과 음성

423개 학습 단위의 한국어와 10개 응용 문단을 파일에 함께 넣었습니다. 이 자료의 듣기·말하기·문단 연결에는 번역 다운로드, 로컬 AI, OpenAI API 키가 필요 없습니다. 새 자료는 사용자가 추가한 유튜브 카드 저장 한도를 차지하지 않습니다.

읽기는 브라우저의 영어 합성 음성을 사용합니다. 출연자의 원본 녹음이나 목소리 복제가 아닙니다. 기기 영어 음성이 있어야 오프라인에서 들을 수 있고, 온라인 음성은 표시된 허용 옵션과 인터넷 연결이 필요합니다. 선택한 문장 외의 대본이나 한국어 뜻을 같이 읽지 않습니다.

브라우저 저장소를 사용할 수 없어도 내장 자료와 준비된 한국어로 연습할 수 있습니다. 이 경우 화면의 기록 저장 안내를 확인하고, 필요한 기록은 내보내세요.

## 검증 결과

- Node/DOM 검사 201개 통과. 기존 185개와 이번 자료 추가 16개를 합친 고유 검사 수입니다.
- 무료 Python 서버·자막·로컬 AI 경로 검사 48개 통과. PDF 두 개의 실제 로컬 HTTP 응답도 원본 파일과 바이트 단위로 비교했습니다.
- 새 영어 청크 423개 전부를 PDF 원문과 대조했습니다. 공백·줄바꿈·서체 제어문자·아포스트로피 표기를 정규화한 텍스트 대응 검사입니다.
- 모든 새 카드의 한국어, 원자료 쪽수, 문장별 연습을 검사했고, 10개 응용 문단에 지정된 학습 문장과 대응 한국어가 포함되는지 확인했습니다.
- 기존 카드 2,874개, 기존 연습 문단 42개, 전이 연습 30개와 원자료 32개를 유지했습니다. 새 원본 PDF 2개를 더해 원본 파일은 총 34개입니다.

음성 이벤트는 모의 환경에서 검증했습니다. 실제 스피커·마이크·Windows 실행기·설치된 음성의 품질·브라우저 화면 배치는 실측하지 못했습니다. 유료 API 호출은 하지 않았습니다. 텍스트 대응 검사가 번역의 모든 뉘앙스를 자동으로 보증하지는 않습니다.
