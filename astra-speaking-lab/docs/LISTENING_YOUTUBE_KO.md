# 문장 듣기 → 한국어 보고 말하기 — v2.5

공부할 때는 문장 카드의 합성 음성으로 그 문장만 듣고 영어를 확인하세요. 말하기 연습을 시작하면 한국어를 먼저 보여 줍니다.

1. 문장별 **음성 듣기 · 이 문장만**으로 소리와 문장을 연결합니다.
2. **한글 보고 한 문장씩 말하기**에서 한국어 내용을 영어로 말합니다. 막힐 때만 영어 답안이나 음성을 확인합니다.
3. 익힌 2~5개 문장을 골라 **여러 문장으로 한글 문단 연습**을 시작합니다.
4. 한글 문단을 보고 학습 문장들을 활용해 이어 말합니다. 새 상황 생성은 무료 로컬 AI로, 원문 내용 연결은 준비된 한국어로 진행합니다.
5. 녹음·자가 점검·복습 평가를 저장합니다. 답변의 정확성이나 발음을 자동 점수화하지 않습니다.
6. **다음 문장 묶음으로 문단 연습**이나 다음 날 복습으로 연결합니다.

추출 개수를 정하지 않고 처음부터 전체 문장을 준비합니다. 더 보기는 이미 추출한 문장을 화면에 펼치는 기능입니다. 한국어 문제를 읽는 것과 영어 정답·음성을 확인하는 것은 구분합니다. 최근 24시간 안에 영어 힌트를 확인한 문장은 독립 인출 성공으로 계산하지 않습니다.

상세 사용법과 실제 검증 범위는 [KOREAN_PRACTICE_KO.md](KOREAN_PRACTICE_KO.md)를 참고하세요.
