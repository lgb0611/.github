# Astra Speaking Lab

**내 자료로 연습하고, 내가 제출할 때만 교정하는 영어 말하기 연습 앱**  
개인 학습용 v1.0 · 제작 기준 2026-09-09 · 공식 OpenAI 제품이 아닙니다.

## 가장 빨리 시작하기

### 자료를 읽고 연습부터 하기 — API 키 없이

ZIP을 폴더에 **모두 압축 해제**한 다음 `OPEN_ME.html`을 Chrome 또는 Edge로 여세요. 표현 설명, 한글 문제, 예시 답안, 자가 비교, 표현별 복습 일정, 학습 기록을 사용할 수 있습니다. 녹음은 브라우저 권한과 기기 지원에 따라 달라집니다. 단독 HTML에서 마이크가 작동하지 않으면 아래 로컬 서버 방식으로 실행하세요.

API 키가 없을 때 자동 음성인식·AI 교정·AI 새 문제 생성은 실행되지 않습니다. 자동으로 맞았다고 평가하는 가짜 채점 기능도 없습니다. 직접 입력하거나 외부 받아쓰기 결과를 붙여넣고 **‘ChatGPT 교정 요청 복사’**를 누른 뒤 현재 ChatGPT 대화에 붙여넣을 수 있습니다. 이것은 수동 전달 방식이지 계정 자동 연결이 아닙니다.

### 앱 안에서 음성인식과 Astra 교정까지 하기 — Windows

1. Python 3.10 이상이 설치되어 있어야 합니다. 없다면 공식 Python 배포판을 설치하세요.
2. ZIP을 전부 압축 해제하고 `start_windows.bat`을 실행하세요.
3. 첫 실행은 `.venv`라는 독립 환경을 만들고 필요한 Python 패키지를 설치합니다. 이때 인터넷이 필요합니다. 보안 경고가 나타나면 파일과 코드를 검토한 뒤 실행 여부를 결정하세요.
4. 브라우저가 열리면 오른쪽 위 **설정**에서 OpenAI API 키를 입력하고, 전송·과금 안내에 동의한 뒤 저장하세요.
5. 기본 모델은 출제·교정 `gpt-6-astra`, 음성인식 `gpt-transcribe`입니다. 실제 계정의 모델 접근 권한과 잔액은 API 요청 시 확인됩니다.
6. 연습 → 녹음 마침 → 음성인식 → 인식 내용 확인 → 답변 제출 순서로 사용하세요.

브라우저가 자동으로 열리지 않으면 주소창에 아래 주소를 입력하세요.

```
http://127.0.0.1:8765
```

터미널 창을 닫거나 Ctrl+C를 누르면 서버가 종료됩니다. 실행 중인 서버를 외부 네트워크에 공개하지 마세요.

### macOS / Linux

Python 3.10 이상 설치 후 압축을 해제한 폴더에서 실행합니다.

```bash
bash start_mac_linux.sh
```

직접 실행하려면 다음 순서도 가능합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python launch.py
```

## 음성 연습에서 끊기지 않는 구조

앱에는 침묵을 듣고 답변이 끝났다고 추정하는 기능이 없습니다. ‘끝’이라는 단어도 필요하지 않습니다.

**녹음 시작 → 필요하면 일시정지/이어서 녹음 → 녹음 마침 → 음성인식 버튼 → 확인란 → 답변 제출 버튼**

녹음을 마쳐도 자동으로 음성인식하거나 교정하지 않습니다. 녹음 중에는 앱의 예문 읽기와 녹음 재생을 막습니다. 브라우저의 다른 탭이나 다른 앱에서 나오는 소리는 제어할 수 없으므로 이어폰을 사용하면 자기 스피커 소리 유입을 줄이는 데 도움이 됩니다.

녹음 파형은 녹음 상태를 나타내는 장식입니다. 음량 측정기나 발음 점수가 아닙니다. 녹음은 24MB 이하만 전송할 수 있습니다. 23MB를 넘으면 파일 제한을 위해 일시정지하지만 자동 제출은 하지 않습니다.

## 어떻게 공부할 것인가

첫날은 **새 표현 3~5개, 한 문단 4~6문장, 15~20분**을 출발점으로 삼으세요. 내장 문단은 5개씩이며, 어려우면 ‘표현 하나씩 짧게 연습’을 먼저 사용하거나 표현 서재에서 1~3개만 골라 새 문제를 만들 수 있습니다.

| 단계 | 실제로 할 일 | 앱 기능 |
|---|---|---|
| 표현 이해 | 뜻·구조·원문·새 예문을 확인 | 표현 카드의 ‘구조 · 예문 · 출처 보기’ |
| 첫 인출 | 영어 표현을 가리고 한글을 영어로 말함 | ‘읽었어요 · 표현 가리고 연습’ |
| 오류 확인 | 실제 발화와 인식 결과를 비교한 뒤 교정 | 원문 보존 + 확인란 + 문장별 교정 |
| 재시도 | 교정문을 읽은 뒤 다시 가리고 말함 | ‘교정문 가리고 다시 말하기’ |
| 새 상황 적용 | 같은 표현을 다른 사건에서 사용 | ‘같은 표현, 다른 상황’ |
| 한국어 의존 줄이기 | 이미 익힌 이야기를 짧은 상황 단서만 보고 설명 | ‘상황 키워드만 보기’ |
| 간격 복습 | 시간이 지난 후 스스로 떠올림 | 표현별 복습 예약 |

교정문을 보고 바로 말한 것은 학습에 도움이 되는 연습이지만, 오래 기억한다고 확인한 것은 아닙니다. 앱은 힌트 사용과 교정 직후 재시도를 독립 인출로 계산하지 않습니다. 같은 날 여러 번 성공해도 독립 인출 횟수를 반복해서 올리지 않습니다.

## 복습 규칙

현재 기본 간격은 **1일 → 3일 → 7일 → 14일 → 30일**입니다. 이는 검증된 보편적 최적값이 아니라 이 앱의 단순한 운영 규칙입니다. 코드 `static/core.js`의 `INTERVALS`에서 바꿀 수 있습니다.

- 떠올리지 못하거나 오류가 있으면 10분 후. 연속 독립 인출 기록과 새 상황 성공 기록을 초기화합니다.
- 힌트를 봤거나 교정 직후 재현한 답은 다음 날. 독립 인출로 계산하지 않습니다.
- 도움 없이 정확히 사용한 답은 간격을 늘립니다. 24시간 안에는 독립 성공을 최대 한 번만 반영합니다.
- ‘독립 인출을 확인한 표현’은 서로 다른 날을 포함한 연속 독립 인출 3회, 최소 2일의 간격, 새 상황 성공을 모두 충족해야 합니다. 이 기준도 앱의 운영 기준이며 영어 실력 인증이 아닙니다.
- AI 결과를 확인한 뒤 사용자가 표현별 평가를 저장해야 복습에 반영됩니다. 자가평가 결과는 객관적 시험 점수가 아닙니다.

## 포함한 학습 자료

### 바로 연습하는 자료

- 가브리엘 잉글리시 1~10강: **핵심 카드 100개**. 각 강 10개.
- 한글 단문과 영어 활용 예문: 핵심 카드마다 1개씩.
- **새 한글 문단 42개**와 영어 예시 답안.
  - 가브리엘: 강당 5개 표현씩 두 묶음, 묶음당 서로 다른 상황 두 개 = 40개.
  - KPOP: 다섯 표현의 서로 다른 상황 두 개 = 2개.
- 예시 답안은 유일한 정답이 아닙니다.

### 원자료를 검색하는 서재

- KPOP 표현 정리 PDF: **220항목**. 파일명에는 219가지라고 되어 있지만 원번호 65가 두 번 있어 둘 다 보존했습니다.
- 연설문 11개: **2,554항목**을 기존 어휘·숙어 해설에서 자동 추출했습니다. 단어·어구·문형이 섞여 있고 모든 항목을 새로 검증한 것은 아닙니다.
- 위 100개 핵심 카드를 포함하여 총 **2,874항목**입니다. 이것을 모두 ‘검증한 고급 숙어’라고 의미하지는 않습니다.
- 원본 스크린샷, KPOP 대본·표현 PDF, 연설문 DOCX는 `sources/`에서 확인할 수 있습니다.

원자료의 문구·기존 해설과 앱 작성 학습 노트·새 예문을 구분해 표시합니다. 원자료에 잘못된 설명이나 오탈자가 있을 수 있으며 그대로 정답이라고 강요하지 않습니다. 새 예문은 별도로 만든 가상 상황이지 강의·영화에서 그대로 나온 대사가 아닙니다. 자동 추출 과정에서 문단·띄어쓰기는 화면에 맞게 정규화했지만 의미나 원자료의 언어 판단을 몰래 바꾸지는 않습니다.

학습 자료의 권리는 원저작자에게 있습니다. 원본 자료를 포함한 이 ZIP은 본인의 개인 학습용이며 공개 업로드·재배포용이 아닙니다. 앱 코드를 공개할 때에는 `sources/`와 원자료가 들어 있는 `library.json`, HTML 내부 데이터도 제거해야 합니다.

## AI 교정의 기준과 한계

1. 실제로 제출한 문장을 그대로 인용합니다. 원문에 없던 말을 사용했다고 평가하지 않도록 프로그램이 인용 문자열을 확인합니다.
2. 의미 오류, 문법 오류, 어휘 결합, 선택적인 문체 개선, 음성인식 확인 필요를 나눕니다.
3. `not`의 누락, 시제, 관사, 전치사, 숫자와 사람을 확인하도록 지시합니다.
4. 자연스러운 다른 영어 표현은 오답과 구분합니다. 단, 목표 표현을 스스로 떠올렸는지는 별도로 봅니다.
5. 학습자가 말하지 않은 이야기를 최소 수정문에 추가하지 않고, 빠진 내용은 따로 표시하도록 지시합니다.
6. 문장 평가가 원문과 다르거나, 존재하지 않는 구절을 인용하면 결과를 보류합니다. 이런 검사는 의미 판단까지 완벽하게 보장하지 않습니다.
7. **자동 교정은 여전히 틀릴 수 있습니다. 발음·억양·CEFR 점수는 제공하지 않습니다.** 텍스트만으로 실제 발음 오류를 확인했다고 주장하지 않습니다.

## API 요금과 개인정보

ChatGPT 구독과 OpenAI API는 별도 결제입니다. 이 앱은 ChatGPT 구독을 API 키처럼 사용할 수 없습니다. API 사용이 부담되면 키 없이 학습하고 ‘ChatGPT 교정 요청 복사’를 쓰세요.

- 녹음 시작/정지/재생/자료 읽기/자가평가/복습 저장: 앱이 OpenAI API를 호출하지 않습니다.
- ‘음성 → 텍스트’: 해당 녹음 파일과 짧은 인식 지침을 전송합니다. 예시 정답과 목표 표현을 음성인식 힌트로 보내지 않습니다.
- ‘답변 제출’: 확인한 영어 텍스트, 한글 문제, 선택한 표현을 전송합니다. 전체 자료나 이전 대화 전체를 보내지 않습니다.
- ‘새 문단 만들기’: 선택 표현, 이전 일부 문제, 주제를 전송합니다.
- 자동 재시도·상시 청취·예약 API 호출은 없습니다. 사용자가 재요청하면 추가 비용이 생길 수 있습니다.
- 설정 화면에 입력한 API 키는 로컬 서버 메모리에만 둡니다. 내보낸 기록이나 브라우저 저장소에 포함하지 않습니다. 서버 종료 시 사라집니다.
- `.env.example`을 `.env`로 복사하여 키를 직접 저장할 수도 있지만, 그 파일에는 키가 평문으로 남습니다. 공유하거나 버전 관리에 올리지 마세요.
- 학습 기록은 이 브라우저의 localStorage에 저장됩니다. 암호화된 금고가 아닙니다. 공용 컴퓨터 사용에 주의하고 정기적으로 내보내세요.
- 녹음 음성은 페이지 메모리에만 남으며 새로고침 시 사라집니다. 필요한 녹음은 ‘녹음 저장’을 누르세요.
- 출제·교정 요청에는 `store:false`를 사용합니다. 이것이 OpenAI 측 모든 보관을 없애거나 무보관을 보장하는 뜻은 아닙니다. 해당 계정의 데이터 정책을 별도로 확인하세요.

## 문제 해결

**마이크가 안 켜짐:** localhost로 연 앱인지 확인하고 브라우저 마이크 허용·운영체제 입력 장치를 확인하세요. 앱은 권한을 대신 변경할 수 없습니다. 파일을 업로드하거나 텍스트를 붙여넣는 방식도 있습니다.

**마이크는 켜졌는데 글자가 안 보임:** 녹음 중 실시간 자막을 생성하지 않는 설계입니다. 녹음을 마친 뒤 ‘음성 → 텍스트’를 직접 누르세요.

**API 키를 넣었지만 실패함:** 해당 계정의 잔액·요청 한도·모델 접근 권한·인터넷을 확인하세요. 기본 모델 ID는 설정에서 변경할 수 있습니다. ‘키 준비됨’은 키가 메모리에 있다는 뜻이며 인증 성공을 미리 검증했다는 뜻이 아닙니다.

**브라우저를 바꾸자 기록이 사라짐:** 브라우저·프로필·주소별로 저장소가 다릅니다. 기존 브라우저에서 내보내기 후 새 환경에서 가져오세요. 단독 HTML 모드와 localhost 모드의 기록도 별개입니다.

**서버 포트가 사용 중임:** 먼저 열린 서버를 사용하거나 종료하세요. `.env`에 PORT를 바꾸면 주소와 보안 Origin 검사에도 같은 값이 적용됩니다.

## 개발 파일

실행에는 `server.py`, `launch.py`, `requirements.txt`, `static/`, `data/`, `sources/`가 사용됩니다. `OPEN_ME.html`은 단독 학습용입니다. `build_page.py`는 수정한 CSS/JS/데이터를 HTML에 다시 묶는 빌더입니다.

`data/build_content.py`는 원본 업로드를 처음 가져오던 개발용 스크립트로, 원본 업로드 경로가 필요합니다. 평상시 앱 실행 시 이 스크립트를 실행할 필요는 없습니다. `data/build_exercises.py`는 내장 문제 데이터 빌더입니다.

앱 코드를 수정한 뒤:

```bash
python build_page.py
```

테스트 실행은 선택 사항이며 개발 도구 pytest, Node.js, Playwright 등이 별도로 필요합니다.

```bash
pytest -q tests/test_server.py
node tests/test_core.js
python tests/test_browser.py
```
