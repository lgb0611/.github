## 시험 대역과 검증하지 못한 범위

제작 환경에 설치된 Chromium은 관리 정책상 URL 이동과 음성 캡처가 차단되어 있습니다. 해당 정책을 변경하지 않았습니다. UI는 Playwright `set_content`로 HTML을 렌더링했고, 마이크(MediaRecorder/getUserMedia), 저장소, 클립보드와 fetch 응답은 시험 대역으로 바꾸었습니다. 따라서 녹음 버튼 이후 자동 제출을 하지 않는 **프런트엔드 제어 흐름**을 확인한 것이며 실제 장치 음성 캡처를 완료했다는 뜻은 아닙니다.

서버의 HTTP 동작은 FastAPI TestClient로 별도 확인했습니다. 로컬 Python 서버 기동과 설정 응답도 확인했습니다. 브라우저와 실제 서버를 통한 전체 실사용 연결, Windows/macOS 기동, 실제 마이크, 기기 TTS, 유료 OpenAI API 요청은 검증하지 않았습니다.

API 테스트는 고정된 JSON·음성인식 응답 대역을 사용했습니다. ‘not’ 누락을 고친 테스트 응답은 **실제 Astra가 이 문장을 자동으로 교정한 사례가 아닙니다.** API 명세를 공식 문서로 확인하고 요청 코드를 작성했지만 계정 권한, 실제 서비스 응답, 시간과 비용은 사용 시 확인해야 합니다.
