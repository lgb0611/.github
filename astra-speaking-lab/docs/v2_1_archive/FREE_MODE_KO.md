# API 없는 학습 개선 — v2.1

2026-09-10. 사용자 요청: API 비용 없이 지속적으로 스피킹 학습하기.

## 달라진 사용 흐름

무료 모드가 매번 기본으로 켜집니다. 유료 자동 기능 버튼을 기본 화면에서 숨기고, 요청 함수에서도 차단합니다. 기존 키와 과금 동의가 있어도 자동으로 유료 기능이 켜지지 않습니다.

텍스트 없이 녹음을 마친 다음 자가 점검을 할 수 있습니다. 녹음을 다시 듣고 예시 답안과 의미·구조를 비교하며, 표현별 자가평가를 저장합니다. 녹음을 인식한 것처럼 가짜 텍스트나 점수를 만들지 않습니다. 기록에는 ‘녹음 자가 점검 · 텍스트 미입력’으로 남습니다.

ChatGPT 교정 요청은 가져오기용 JSON을 요구합니다. 사용자가 요청과 결과를 직접 복사하면 앱의 문장별 교정·오류 노트·복습 일정과 연결됩니다. request_id, 표현 ID, 실제 인용, 수정 구절, 최종 교정문을 검사합니다. 언어 판단의 옳고 그름을 자동 증명하는 검사는 아닙니다.

요청 당시 답변과 힌트 상태를 고정해 저장합니다. 이후 답변을 바꾸면 그대로 적용하지 않고 원래 답변으로 돌아가도록 안내합니다. 이미 최근에 평가한 표현의 일정을 오래된 가져오기 결과가 되돌리지 않게 했습니다. 동일 결과의 중복 가져오기도 막습니다.

무료 전용 실행기는 Python 표준 라이브러리만 사용합니다. API 클라이언트와 키 파일을 읽는 코드가 없고, API의 POST 요청은 모두 거절합니다. 127.0.0.1에만 열고 학습 HTML·원자료만 제공합니다. 설정 파일이나 상위 디렉터리 접근은 허용하지 않습니다. 서버 없이 OPEN_ME.html만으로도 사용할 수 있습니다.

## 자동 검증 75개

- 복습·백업·콘텐츠·외부 교정 데이터 로직: 33개.
- DOM 상호작용: 37개. 무료 기본값, 키가 있어도 유료 요청 차단, 녹음만으로 평가, ChatGPT 결과 가져오기, 오류 노트, 잘못된 연결 거절·원문 복원, 새로고침 후 대기 요청 복원, 늦은 평가의 일정 보호, 로컬 음성만 선택하는 동작을 포함합니다.
- 실제 로컬 HTTP: 5개. HTML/config 응답, 유료 요청 거절, 원자료 접근과 경로 제한, 외부 Host 거절, HEAD 응답.

무료 서버는 Python의 추가 패키지 경로를 사용하지 않는 `-S` 옵션으로 실행하고 시험했습니다. v2.0에서 수행한 서버/API 검사 40개는 이번에 재실행하지 않았으며 총계에 포함하지 않았습니다. 과거 검사 결과는 docs/v2_archive에 보존했습니다.

빌드 결과의 단독/서버 HTML 일치, JavaScript/Python 구문, 원자료 32개 보존, ZIP 무결성도 확인합니다. 새 알고리즘으로 언어 실력 향상 효과를 실험한 것은 아닙니다.

## 확인하지 못한 부분

브라우저는 연결됐지만 로컬 주소 접근이 `ERR_BLOCKED_BY_CLIENT`로 차단되어 실제 렌더링 검증은 하지 못했습니다. DOM 시뮬레이션을 실제 브라우저 테스트로 표현하지 않습니다. 실제 기기 마이크·스피커·Windows 음성 입력, Windows/macOS 실행기 더블클릭, 실제 ChatGPT 출력의 형식 준수율, 유료 OpenAI 호출은 시험하지 않았습니다.

ChatGPT와 Windows 음성 입력은 인터넷 서비스입니다. 완전 오프라인으로 가능한 것은 자료 학습, 녹음, 설치된 기기 음성 듣기, 자가 점검, 복습입니다. 오프라인 자동 문법 교정이나 음성인식 모델은 포함하지 않았습니다.

## 확인한 공식 안내

- [Microsoft 음성 입력](https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc): Windows + H, 영어 입력 언어 선택, 인터넷 필요. Fluid dictation은 문법을 자동 바꿀 수 있어 실제 발화 연습에서는 끄도록 안내했습니다.
- [OpenAI의 ChatGPT/API 결제 구분](https://help.openai.com/en/articles/9039756-billing-settings-in-chatgpt-vs-platform): 두 서비스의 결제 체계가 분리되어 있습니다. 이 앱은 ChatGPT 구독으로 API를 이용하는 기능을 제공하지 않습니다.
