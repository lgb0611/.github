# Astra Speaking Lab 2.1 — API 없이 학습하기

**API 키나 결제 설정 없이 녹음하고, 비교하고, 복습하는 영어 스피킹 앱입니다.**
새로 열 때마다 무료 모드로 시작합니다. 이전에 키를 연결했어도 이 창에서 유료 기능을 직접 켜기 전에는 API 요청을 보내지 않습니다.

## 바로 시작하기

1. ZIP을 전부 압축 해제합니다.
2. **OPEN_ME.html**을 Chrome 또는 Edge로 엽니다. 설치나 API 키가 필요 없습니다.
3. **오늘의 연습 시작**을 누릅니다.
4. 표현을 익힌 뒤 **읽었어요 · 표현 가리고 연습**을 누르고 말합니다.
5. **녹음 시작 → 녹음 마침 → 말한 답변 자가 점검**을 누릅니다. 텍스트를 입력하지 않아도 됩니다.
6. 내 녹음과 예시를 비교하고, **표현별 평가 → 이 평가로 복습 일정 저장 → 다음 표현**으로 진행합니다.

자동으로 정답이나 발음 점수를 매기지는 않습니다. 자연스러운 다른 표현도 가능하므로 예문과 단어가 다르다고 오답은 아닙니다. 판단이 어려운 표현은 ‘확인 필요 / 오류’로 저장하고 다시 확인하세요.

**기존 기록은 이전 앱의 ‘복습 · 기록 → 기록 내보내기’로 먼저 백업하세요.** 새 앱의 오른쪽 위 설정 → 기록 가져오기에서 JSON을 불러올 수 있습니다. 같은 브라우저·프로필·주소에서는 v1/v2 기록을 이어서 읽습니다. 단독 HTML의 폴더, 브라우저, 주소의 localhost/127.0.0.1 또는 포트가 바뀌면 자동으로 이어지지 않을 수 있습니다. 가져오기는 현재 기록을 교체하며 병합하지 않습니다.

## 마이크 때문에 로컬 실행이 필요할 때

HTML 파일에서 마이크 권한을 사용할 수 없다면 아래 **무료 실행기**를 사용하세요. Python 3.10 이상은 필요하지만 추가 패키지 설치, API 키, 인터넷 연결은 필요 없습니다.

- Windows: **start_free_windows.bat**
- macOS / Linux: `bash start_free_mac_linux.sh`
- 브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:8765/`를 엽니다.
- 기존 실행 창이 있다면 종료한 뒤 실행하세요. 같은 포트가 사용 중이면 무료 실행기는 중단합니다.
- 실행 창에서 Ctrl+C를 누르면 종료됩니다.

이 실행기는 API 키 파일을 읽지 않으며 음성인식·교정·출제 API 경로 자체가 없습니다. 학습 화면과 원자료만 제공합니다. 마이크 접근 권한은 브라우저에서 허용해야 합니다.

## API 요금 없이 ChatGPT로 문장 교정하기

앱이 ChatGPT 계정에 자동 연결되는 방식은 아닙니다. 사용 중인 ChatGPT에서 요청과 결과를 직접 복사합니다. ChatGPT의 이용 한도는 적용되지만 앱의 OpenAI API 호출은 없습니다. [ChatGPT와 API 결제 안내](https://help.openai.com/en/articles/9039756-billing-settings-in-chatgpt-vs-platform)

1. 내가 실제로 말한 문장을 입력하거나 기기의 받아쓰기 결과를 붙여 넣습니다.
2. 인식 오류만 고친 뒤 **인식된 내용이 실제 발화와 같은지 확인했습니다**를 체크합니다.
3. **ChatGPT 교정 요청 복사**를 누르고 ChatGPT 대화에 붙여 넣습니다.
4. ChatGPT가 출력한 **JSON 전체**를 복사합니다. `request_id`와 `result`가 들어 있는 객체입니다.
5. 앱에서 **교정 결과 가져오기 → 붙여넣기 → 확인하고 교정 가져오기**를 누릅니다.
6. 문장별 수정·이유를 확인하고 표현별 복습 평가를 저장합니다. 실제 오류는 **복습 · 기록 → 다시 말할 오류 노트**에 모입니다.

요청 후 문제나 답변을 바꾸면 결과를 잘못 붙이지 않도록 거절합니다. ‘요청했던 답변으로 돌아가기’로 원래 입력을 복원한 뒤 해당 JSON을 가져오세요. 마지막 복사 요청 한 건은 기록에 저장되어 새로 열어도 이어집니다. 새로운 다른 요청을 복사하면 이전 대기 요청은 교체됩니다.

요청 ID, 실제 발화 인용, 표현 ID, 수정 근거, 누락된 문장, 전체 수정문과 문장별 수정의 일치를 검사합니다. **이 검사가 ChatGPT의 의미·문법 판단 자체를 보증하지는 않습니다.** 형식이 맞지 않으면 원본 요청과 오류 안내를 ChatGPT에 보내 JSON을 다시 요청하세요. 교정을 가져와도 복습 평가는 사용자가 확인하고 저장합니다. 오래된 결과가 더 최근 평가의 복습 일정을 덮어쓰지 않도록 했습니다.

교정 요청을 복사한 후에는 외부에서 영어 표현과 교정을 읽을 수 있으므로 이후 시도는 힌트 연습으로 기록합니다. 요청을 복사하기 직전에 한 답변의 힌트 상태는 따로 보존합니다.

## 타이핑을 줄이는 방법

Windows에서 입력 언어를 영어로 바꾸고 답변 입력란을 클릭한 뒤 **Windows + H**를 누르면 기기의 음성 입력을 사용할 수 있습니다. 인터넷과 Microsoft 음성 서비스가 필요하며 OpenAI API 키는 필요 없습니다. 받아쓰기 설정에 **Fluid dictation**이 보이면 끄세요. 이 기능은 문법을 자동으로 바꿀 수 있어 실제 발화를 확인하는 연습에 맞지 않습니다. [Microsoft 음성 입력 안내](https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc)

완전 오프라인에서는 녹음만으로 자가 점검하거나 직접 입력합니다. 앱에는 오프라인 자동 음성인식 모델이 포함되어 있지 않습니다. 예문 듣기는 기기에 설치된 영어 음성을 사용하며, 로컬 영어 음성이 없으면 설치 안내를 표시합니다. 온라인 음성으로 자동 전환하지 않습니다.

## API 없이 새 문제 추가하기

표현 서재에서 1~5개 선택 → **출제 요청 복사** → ChatGPT에 붙여넣기 → 받은 JSON을 **문제 가져오기**에 붙여넣습니다. 답안을 함께 볼 수 있어 첫날은 힌트 연습으로 기록합니다. 이미 준비된 단문과 문단만 사용해도 됩니다.

## 학습과 복습 규칙

- 오늘의 연습은 오래 밀린 표현부터 선택합니다. 새 표현 최대 3개, 전체 최대 8개입니다.
- 한 표현씩 짧게 말하고, 익숙해지면 문단과 새 상황으로 옮깁니다.
- 기본 복습 간격은 1 → 3 → 7 → 14 → 30일입니다.
- 떠올리지 못했거나 오류가 있으면 10분 뒤에 다시 확인합니다.
- 힌트·교정 직후 재현은 독립 인출로 세지 않습니다. 이미 더 가까운 복습이 있으면 늦추지 않습니다.
- 최근 24시간 내 카드·서재·예시·피드백을 본 표현은 힌트 연습으로 기록합니다.
- 복습 시점에 도움 없이 성공한 경우에만 간격을 늘립니다. 같은 날 반복하거나 예정일보다 먼저 성공하면 날짜를 유지합니다.
- 최소 3회 독립 성공, 시간 간격, 처음 시도한 다른 상황에서의 독립 성공이 있어야 앱의 ‘독립 인출 확인’으로 표시합니다. 자가평가의 정확성을 앱이 인증하는 것은 아닙니다.

이 수치들은 앱의 운영 규칙이며 개인에게 검증된 최적 학습량이나 숙달 인증 기준이 아닙니다. 15~20분은 시작을 위한 제안입니다. 녹음은 침묵이나 타이머로 자동 제출하지 않습니다. 학습 요약 복사는 영어 학습 내용만 출력합니다.

## 포함 자료

- 가브리엘 1~10강 핵심 카드 100개와 한글 단문·영어 예문.
- 기존 문단 42개와 8~10강 짧은 새 상황 30개.
- KPOP 220항목, 연설문 자동 추출 2,554항목. 서재 총 2,874항목.
- 원본 이미지·PDF·DOCX 32개를 `sources/`에 보존했습니다.

v2 작업에서 핵심 100개 예시 쌍과 기존 42개 문단 쌍을 읽고 검토했습니다. 원본 전체와 자동 추출 항목의 언어 품질을 전수 검증한 것은 아닙니다. 원자료와 앱 작성 예문은 구분합니다. 이번 v2.1에서는 학습 자료 내용을 변경하지 않았습니다.

## 기록과 음성 보관

학습 기록·입력·가져온 교정은 이 브라우저의 localStorage에 저장됩니다. 녹음은 페이지 메모리에만 남으므로 필요한 파일은 **녹음 저장**으로 별도 보관하세요. 브라우저 데이터 삭제나 폴더 이동 전에 기록을 내보내세요. 저장 실패나 다른 탭과의 충돌은 화면에 알립니다.

이 패키지는 개인 학습용이며 공식 OpenAI 제품이 아닙니다. 원자료를 담은 HTML·JSON·문서를 공개 재배포하지 마세요.

## 선택 사항: 유료 API 기능

현재 목적에는 사용할 필요가 없습니다. 자동 연결을 원할 때만 기존 `start_windows.bat` 또는 `start_mac_linux.sh`로 API 서버를 실행하고, 설정의 접힌 **선택 사항 · 유료 API 연결**을 펼쳐 **이 창에서 유료 API 기능 켜기**, 키 입력, 과금 동의, 연결 저장을 진행합니다. 페이지를 새로 열면 무료 모드로 돌아갑니다. 설정 저장만으로 키의 실제 접근 권한을 확인한 것은 아닙니다.

입력한 키는 API 서버 메모리에 보관하고 서버 종료 시 사라집니다. `.env`에 직접 저장한 키는 파일에 남습니다. 메모리 키 삭제는 설정에서 할 수 있습니다. 별도 API 요금이 발생하는 자동 기능을 무료로 제공한다고 약속하지 않습니다.

## 검증

v2.1 자동 검사 **75개 통과**: 복습·백업·교정 JSON 로직 33, DOM 상호작용 37, 실제 로컬 HTTP 요청 5. 무료 서버는 Python 표준 라이브러리만 사용한 실행도 확인했습니다. 과거 v2의 서버/API 검사 40개는 이전 검증 기록으로 보존했으며 이번 75개에 합산하지 않았습니다.

실제 브라우저 화면은 검증 환경의 로컬 주소 접근 차단(`ERR_BLOCKED_BY_CLIENT`)으로 확인하지 못했습니다. 실제 기기 마이크·스피커·Windows 받아쓰기·Windows/macOS 실행기 더블클릭·실제 ChatGPT 응답의 가져오기 성공률·유료 API 실호출도 미검증입니다. 음성·클립보드와 AI 결과는 DOM 검사에서 모의 데이터를 사용했습니다.

자세한 변경 내용과 한계: `docs/FREE_MODE_KO.md`. v2 보고서와 이전 화면은 과거 기록입니다.

## 개발·재검증

앱 사용에는 Node.js가 필요 없습니다. 개발 시 HTML은 아래 명령으로 생성합니다.

```bash
python build_page.py
# 추가 Python 패키지 없이 무료 서버를 검증합니다.
python -S -m unittest discover -s tests -p test_free_server.py -v
# Node.js 22.22.2+ 또는 24.15.0+ 및 개발용 jsdom
npm ci
npm test
# 기존 API 서버 전체 검증에는 해당 의존성과 pytest가 필요합니다.
python -m pytest
```

학습 설계의 기존 근거와 콘텐츠 검토 범위는 `docs/UPGRADE_REPORT_KO.md`를 참고하세요.
