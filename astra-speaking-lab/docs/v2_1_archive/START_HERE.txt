Astra Speaking Lab 2.1 — API 없이 학습

1. ZIP을 전부 압축 해제하세요.
2. OPEN_ME.html을 Chrome 또는 Edge로 여세요.
3. 오늘의 연습 시작 → 표현 익히기 → 표현 가리고 말하기.
4. 녹음 마침 → 말한 답변 자가 점검 → 복습 일정 저장.

API 키나 결제가 필요 없습니다. 녹음만으로도 자가 점검할 수 있습니다.
페이지를 새로 열면 무료 모드로 시작하고 유료 API 요청은 차단됩니다.

마이크가 HTML 파일에서 동작하지 않으면:
- Python 3.10 이상이 있는 Windows: start_free_windows.bat
- macOS/Linux: bash start_free_mac_linux.sh
- 추가 패키지 설치와 API 연결은 필요 없습니다.
- 이전 실행 창이 있으면 먼저 종료하세요.
- 브라우저 주소: http://127.0.0.1:8765/

문장 교정이 필요하면:
실제 발화 입력 → 발화 확인 체크 → ChatGPT 교정 요청 복사
→ ChatGPT에 붙여넣기 → 받은 JSON 전체 복사
→ 앱의 교정 결과 가져오기 → 확인 → 복습 평가 저장.
앱에서 API를 호출하지 않습니다. ChatGPT의 기존 이용 한도는 적용됩니다.

Windows 받아쓰기: 영어 입력 언어 → 입력란 클릭 → Windows + H.
인터넷과 Microsoft 음성 서비스가 필요합니다.
설정에 Fluid dictation(자동 문장 교정)이 있으면 끄세요.

이전 버전의 복습·기록에서 기록 내보내기를 먼저 하세요.
새 버전 오른쪽 위 설정 → 기록 가져오기로 백업을 불러옵니다.
녹음 파일은 녹음 저장으로 별도 보관하세요.
