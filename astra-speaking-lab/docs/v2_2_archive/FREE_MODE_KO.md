# API 없는 학습 — v2.2

기존 무료 모드에 듣기 우선 학습, 음성 선택·테스트, 유튜브 표현 저장과 원본 구간 듣기를 추가했습니다.

- 매번 무료 모드로 시작하고 유료 OpenAI 요청을 차단합니다.
- 녹음만으로 자가 점검·복습 저장이 가능합니다. 음성 인식이나 발음 점수를 꾸며내지 않습니다.
- 문장 교정은 요청과 JSON을 ChatGPT와 직접 복사해 사용할 수 있습니다. 기존 이용 한도는 적용됩니다.
- 기기 영어 음성이 기본입니다. 브라우저의 온라인 음성은 별도 허용한 경우만 사용할 수 있습니다.
- YouTube 원본 영상은 사용자가 재생할 때만 연결합니다. 자동 자막은 선택 실행기를 설치하고 버튼을 눌렀을 때 공개 영어 자막을 읽습니다.
- 자막 접근 실패 시 붙여넣기·TXT/SRT/VTT 파일로 계속할 수 있습니다.

현재 사용 안내와 검증 범위는 [듣기·유튜브 학습 안내](LISTENING_YOUTUBE_KO.md), 전체 사용법은 [README](../README_KO.md)를 보세요. 이전 v2.1 설명과 75개 검사 기록은 `v2_1_archive/`에 보존했습니다. 현재 104개 검사에는 이전 유료 서버 검사 40개를 합산하지 않았습니다.
