# 듣고 꺼내 쓰는 학습안과 유튜브 기능 — v2.2

2026-09-10

이번 변경은 유료 API 없이 학습하기, 예문 듣기 문제 해결, 유튜브에서 표현을 가져와 말하기 연습으로 연결하기 위한 것입니다. 전달받은 공유 대화 링크의 본문은 이 환경에서 읽지 못했습니다. 따라서 해당 대화 전체를 반영했다고 주장하지 않으며, 확인된 듣기·표현 인출의 어려움을 기준으로 만든 초안입니다.

## 1. 공부 순서를 이렇게 바꿉니다

**소리 → 상황과 의미 → 짧게 따라 말하기 → 글자 없이 말하기 → 다른 상황 → 다음 날 복습** 순서로 시작합니다. 처음부터 한국어 문장 전체를 영어로 옮기게 하기보다, 짧은 장면에서 들은 표현을 다시 쓰는 연습을 중심에 둡니다.

하루 20분과 표현 3개는 부담을 조절하기 위한 시작값입니다. 이 시간과 개수가 개인에게 최적이라고 검증된 것은 아닙니다.

| 시간 | 무엇을 하나요? | 끝났다고 볼 기준 |
|---|---|---|
| 3분 | 어제 표현을 짧은 상황 단서만 보고 한 문장씩 말하기 | 먼저 영어를 읽지 않고 시도했다 |
| 3분 | 오늘 영상의 1~2분 구간을 자막 없이 듣기 | 누가 어떤 상황에서 무슨 뜻을 말하는지 대략 설명했다 |
| 4분 | 안 들린 부분을 자막으로 확인하고 표현 3개를 짧게 따라 말하기 | 소리와 실제 단어를 대조했다 |
| 4분 | 글자를 가리고 원래 내용을 내 말로 설명하기 | 원문과 다른 문장이어도 같은 뜻을 전달했다 |
| 4분 | 같은 표현을 다른 상황에서 한 문장씩 사용하기 | 외운 원문을 반복하는 것에서 한 번 더 나아갔다 |
| 2분 | 녹음·예시를 비교하고 표현별 평가 저장하기 | 확인할 오류와 다음 복습을 정했다 |

처음부터 안 들리는 문장을 계속 반복 재생하지 마세요. 1~2번 듣고 막힌 부분을 확인한 뒤, 짧게 나눠 듣고 다시 전체 구간으로 돌아갑니다. 필요하면 영상 설정에서 속도를 낮췄다가 원래 속도로 다시 듣습니다. 난도가 높으면 영상 범위나 새 표현 수를 줄입니다.

한국어는 의미를 확인하거나 짧은 상황을 떠올리는 단서로 사용할 수 있습니다. 예를 들어 “주말 계획을 아직 고민 중” 같은 단서를 보고 한 문장을 말합니다. 긴 한국어 정답 문장을 통째로 외울 필요는 없습니다.

기록할 때는 “바로 따라 말할 수 있었다”와 “다음 날 혼자 꺼내 쓸 수 있었다”를 구분합니다. 앱은 최근 24시간 안에 영어 카드·자막·모범 답·원본 음성을 확인한 표현을 도움받은 연습으로 보수적으로 기록합니다. 복습 시점에 도움 없이 성공해야 1·3·7·14·30일 간격이 늘어납니다. 이는 앱의 운영 규칙이며 실력 인증이 아닙니다.

## 2. 유튜브 학습 실행하기

Windows: ZIP을 전부 압축 해제하고 **start_youtube_windows.bat**을 실행합니다. Python **3.10~3.14**가 필요합니다. 처음 한 번 공개 자막 도구를 별도 환경에 설치하므로 인터넷이 필요합니다. 기존 실행 창이 있으면 종료한 뒤 시작하세요.

macOS/Linux: `bash start_youtube_mac_linux.sh`. 브라우저가 열리지 않으면 `http://127.0.0.1:8765/`로 접속합니다.

1. **유튜브 듣고 말하기**에서 동영상 한 편의 링크를 입력하고 **영상 연결**을 누릅니다. Watch·짧은 공유 링크·Shorts 링크를 지원합니다. 채널이나 재생목록 전체는 대상이 아닙니다.
2. 시작·끝을 짧게 잡고 **이 구간 듣기**를 누른 다음 영상의 재생 버튼을 누릅니다. 앱이 자동으로 재생을 시작하지 않습니다. 처음에는 YouTube의 CC를 끄세요.
3. **영어 자막 자동 불러오기**로 공개 영어 자막을 준비합니다. 자막은 자동으로 펼쳐지지 않습니다. 먼저 들은 다음 **영어 자막 확인하기**를 누릅니다.
4. 후보 표현을 누르거나 **근거가 되는 자막**에서 직접 구절을 골라 **익힐 표현**에 원문 그대로 입력합니다. 앞뒤 자막이 짧게 끊긴 경우에는 이어진 자막을 묶어 후보를 찾습니다.
5. 뜻과 짧은 상황 단서를 확인합니다. **표현 구간 듣기**로 실제 소리·자막·시간이 맞는지 확인하고 **내 표현으로 저장하고 말하기**를 누릅니다.
6. 스피킹 화면에서 **영상 속 표현 먼저 듣기 → 소리·뜻 확인했어요 · 가리고 말하기 → 녹음 → 말한 답변 자가 점검**으로 진행합니다.
7. 표현별 평가를 고르고 **이 평가로 복습 일정 저장**을 누릅니다. 저장한 표현은 서재의 ‘유튜브 내 표현’, 자료 선택의 ‘유튜브에서 익힌 내 표현’, 오늘의 연습과 복습에서 다시 사용할 수 있습니다.

YouTube 재생 구간은 플레이어가 지원하는 초 단위로 설정합니다. 실제 시작 위치가 약간 앞당겨지거나 자막 경계와 어긋날 수 있으므로 직접 들어 보고 조절하세요. 삽입 재생을 막은 영상은 **YouTube에서 열기**로 듣습니다. [공식 플레이어 구간 설정](https://developers.google.com/youtube/player_parameters), [공식 재생 오류 안내](https://developers.google.com/youtube/iframe_api_reference)

## 3. 자동 자막이 안 될 때

영상에 영어 자막이 없거나, YouTube가 자동 접근을 제한하거나, 네트워크 요청이 실패할 수 있습니다. 앱은 실패 이유와 붙여넣기 안내를 표시하고 입력해 둔 자막을 유지합니다.

- YouTube의 영상 설명에서 **스크립트 표시**를 열고 영어 자막을 복사합니다. 자막이 제공되는 영상에서 사용할 수 있습니다. [YouTube 안내](https://support.google.com/youtube/answer/15930243?hl=en)
- 앱의 **자막 편집 · 붙여넣기 · 파일 가져오기**를 펼쳐 붙이고 **자막에서 표현 후보 찾기**를 누릅니다. TXT·SRT·VTT 파일도 가능합니다.
- 시간 없는 원문도 읽을 수 있습니다. 다만 앱이 시간 위치를 추정해 사실처럼 만들지 않으므로, 저장할 표현의 시작·끝은 원본에서 직접 확인해 입력해야 합니다.
- 시작 시간만 있는 복사 자막은 다음 자막 시점 또는 짧은 기본 길이로 끝을 잡고 화면에 추정값임을 표시합니다. 실제 발화를 듣고 조절하세요.
- 영어 원문 자체가 없는 영상에는 자동 번역이나 오프라인 음성 인식을 제공하지 않습니다. 영어 자막이 있는 다른 영상으로 시작하거나 직접 받아쓴 원문을 사용하세요.

`OPEN_ME.html`과 기존 무료 실행기도 자막 붙여넣기·표현 저장·녹음·복습을 지원합니다. 파일 주소로 연 화면은 YouTube 삽입 재생이 제한될 수 있어 외부 원본 링크를 제공합니다.

공개 자막 읽기는 `youtube-transcript-api 1.2.4`를 선택적으로 사용합니다. YouTube 공식 자막 다운로드 API는 권한이 필요한 별도 방식이므로 이 앱의 공개 자막 읽기와 구분해야 합니다. 앱에는 로그인 쿠키·차단 우회·자동 재시도 기능을 넣지 않았습니다. [도구 설명과 접근 제한](https://github.com/jdepoix/youtube-transcript-api), [설치 버전](https://pypi.org/project/youtube-transcript-api/1.2.4/), [공식 자막 다운로드 권한](https://developers.google.com/youtube/v3/docs/captions/download)

## 4. 표현 추출과 새 상황 만들기의 범위

| 기능 | 작동 방식 | 확인할 점 |
|---|---|---|
| 기본 표현 후보 | 정해진 영어 패턴을 자막 원문에서 로컬 검색 | 모든 표현을 찾지 못하며 한국어 뜻은 문맥에 맞게 확인 |
| 내가 고른 표현 | 원문에 실제로 포함된 구절을 직접 저장 | 자동 자막 오류는 원래 음성과 대조 |
| 문맥에 맞는 선정·새 상황 | 요청을 ChatGPT에 복사하고 JSON 결과를 앱에 가져오기 | 앱이 ChatGPT 계정에 자동 연결되지는 않음 |
| 원본 듣기 | 저장한 자막에 연결된 영상 구간 재생 | 새 가상 상황의 예문을 원래 화자가 말한 것처럼 취급하지 않음 |
| 예문 듣기 | 기기 또는 허용한 브라우저 영어 음성 | 기기마다 음성 목록과 재생 지원이 다름 |
| 문장 점검 | 녹음 자가 점검 또는 ChatGPT 교정 결과 가져오기 | 무료 모드의 자동 문법·발음 채점은 없음 |

**ChatGPT로 문맥에 맞는 표현·새 상황 만들기**를 펼치고 **표현 추출 요청 복사**를 누릅니다. 현재 구간 자막을 ChatGPT에 직접 붙여넣고, 반환된 JSON 전체를 **표현과 새 상황 가져오기**에 넣습니다. OpenAI API 요금은 발생하지 않으며 ChatGPT의 기존 이용 한도는 적용됩니다.

가져올 때 영상 ID, 자막 구간 ID, 원문 전체, 표현이 실제 원문에 포함되는지를 검사합니다. 모델이 임의로 준 재생 시간은 사용하지 않습니다. 자막에 시간이 없는 경우에는 먼저 수동으로 시간을 지정해 표현을 저장하세요. JSON 형식과 인용 검사는 한국어 뜻이나 새 예문의 자연스러움을 보증하지 않습니다.

영상 표현 1개에서 **같은 표현, 다른 상황**을 누르면 가져온 새 상황을 사용할 수 있습니다. 준비된 새 상황이 없다면 서재에서 표현을 선택하고 **출제 요청 복사**를 사용하세요. 유튜브 사용자 표현의 유료 자동 출제·자동 교정은 지원하지 않으며 무료 복사 기능을 안내합니다.

## 5. 기존 예문이 안 들릴 때

**스피킹 연습 → 예문 소리가 안 나나요? · 영어 음성 설정**에서 **목록 새로 읽기 → 영어 음성 선택 → 음성 테스트**를 합니다.

이전 코드에서 로컬 영어 음성만 허용하던 제약과 브라우저 음성 목록이 늦게 도착하는 경우를 처리했습니다. 영어 음성을 선택하고 테스트할 수 있으며 긴 예문은 문장별로 나눠 재생합니다. 실패가 발생하면 오류를 표시합니다. [음성 목록 갱신 이벤트](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/voiceschanged_event)

로컬 영어 음성이 없으면 Windows에 영어 음성을 설치하거나, **브라우저의 온라인 영어 음성도 허용**을 직접 선택합니다. 온라인 음성은 예문을 선택한 서비스에 전송할 수 있으며 OpenAI API 키를 사용하지 않습니다. 이 설정은 기록에 저장됩니다. [로컬·원격 음성 구분](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)

유튜브 표현은 기기 음성 없이도 원본 영상으로 들을 수 있습니다. 실제 사용자 기기의 재생 성공은 이 환경에서 확인하지 못했으므로 먼저 음성 테스트와 원본 재생으로 확인하세요.

## 6. 보관과 비용

유료 API 기능은 페이지를 열 때마다 꺼져 있고 무료 실행기는 유료 요청을 거절합니다. YouTube 영상·자막, 선택한 온라인 음성, 사용자가 직접 여는 ChatGPT는 인터넷 연결이 필요합니다. 이들을 완전 오프라인 기능으로 표시하지 않습니다.

유튜브 표현·연결된 시간·학습 기록과 최근 편집 자막은 이 브라우저에 저장됩니다. 내 표현은 최대 500개이며 기록 내보내기에 포함됩니다. 예전 앱에서 기록을 먼저 내보내고 새 버전의 설정에서 가져오세요. 브라우저 프로필·파일 위치·로컬 주소가 달라지면 기록이 자동으로 이어지지 않을 수 있습니다. 기록 가져오기는 교체 방식입니다.

음성 파일과 YouTube 영상은 학습 기록에 포함하지 않습니다. 내 녹음이 필요하면 **녹음 저장**으로 따로 보관합니다. 자막은 읽기·불러오기 후 저장되며, 최근 영상의 편집 자막 한 건을 보관합니다. 저장한 표현의 원문은 영상 전환 후에도 남습니다.
