Astra Speaking Lab 2.2 — 듣고, 내 말로. 유료 API 없이.

기존 앱에서 복습·기록 → 기록 내보내기를 먼저 하세요.
새 버전의 설정 → 기록 가져오기로 백업을 불러올 수 있습니다.
ZIP을 모두 압축 해제한 뒤 시작하세요.

[유튜브 링크로 연습 — Windows]
1. Python 3.10~3.14가 있으면 start_youtube_windows.bat 실행.
   처음 한 번 자막 읽기 패키지를 인터넷에서 설치합니다. API 키·결제 없음.
2. 유튜브 듣고 말하기 → 링크 붙이기 → 영상 연결.
3. 1~2분 구간 설정 → 이 구간 듣기 → 영상 재생. 처음에는 CC를 끄세요.
4. 영어 자막 자동 불러오기 → 영어 자막 확인하기.
5. 표현 후보 선택 → 뜻 확인 → 내 표현으로 저장하고 말하기.
6. 글자 가리고 말하기 → 녹음 → 자가 점검 → 복습 일정 저장.

자막이 없거나 YouTube가 접근을 제한하면:
YouTube의 스크립트 표시에서 영어 자막을 복사해 붙이거나 TXT/SRT/VTT 파일을 가져오세요.
자막의 시간 정보가 없으면 실제 표현 구간의 시작·끝을 직접 지정하세요.

[기존 자료로 바로 연습]
OPEN_ME.html을 Chrome/Edge로 열면 설치 없이 시작합니다.
오늘의 연습 시작 → 예문 먼저 듣기 → 표현 보기 → 가리고 말하기.
파일에서 마이크가 안 되면 start_free_windows.bat을 실행하세요.
무료 실행기는 Python 3.10+가 필요하며 추가 패키지는 설치하지 않습니다.
영상이 파일 화면에서 재생되지 않으면 YouTube에서 열기를 사용하세요.

[예문 소리가 안 날 때]
스피킹 연습 → 예문 소리가 안 나나요? · 영어 음성 설정
→ 목록 새로 읽기 → 음성 선택 → 음성 테스트.
기기 영어 음성이 없으면 설치하거나 온라인 영어 음성 허용을 직접 선택하세요.
온라인 음성은 브라우저 음성 서비스로 예문을 보낼 수 있고 OpenAI API는 사용하지 않습니다.
유튜브 원래 소리는 영상 속 표현 먼저 듣기를 사용하세요.

[다른 상황 만들기 / 문장 교정]
표현 추출 요청이나 교정 요청 복사 → ChatGPT에 붙여넣기
→ 받은 JSON 전체를 앱에 가져오기.
앱의 API 호출은 없으며 ChatGPT의 이용 한도는 적용됩니다.
자동 후보는 기본 표현 패턴을 찾습니다. 문맥상 뜻은 확인하세요.

[실행기 공통]
기존 실행 창을 먼저 종료하세요. 주소: http://127.0.0.1:8765/
종료: 실행 창에서 Ctrl+C.
macOS/Linux: bash start_youtube_mac_linux.sh 또는 bash start_free_mac_linux.sh
무료 모드가 기본이며 유료 OpenAI 요청은 차단됩니다.
녹음 파일은 녹음 저장으로 따로 보관하세요.
