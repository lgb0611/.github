# 주요 표현 자동 학습 — v2.3

이번 버전은 표현·한국어 뜻·말하기 상황을 직접 작성하던 단계를 없앴습니다. 자막에서 주요 표현을 골라 설명과 새 상황을 준비하고, 저장·말하기 연습·복습으로 연결합니다. 직접 편집은 접힌 고급 메뉴에서 선택적으로 사용할 수 있습니다.

## 사용 순서

기존 앱의 ‘기록 내보내기’로 백업한 뒤 새 ZIP을 모두 압축 해제하세요. 이전 실행 창을 종료하고 **start_youtube_windows.bat**을 실행합니다. Python 3.10~3.14가 필요하며 자막 구성 요소는 최초 한 번 설치합니다.

1. **유튜브 듣고 말하기 → 링크 입력 → 이 영상으로 자동 학습 만들기**.
2. 이미 자막을 불러온 화면이라면 **이 구간의 주요 표현 자동 추출**만 누릅니다. 기본은 3개이며 5개도 선택할 수 있습니다.
3. 표현·뜻·설명·새 말하기 상황이 완성된 카드로 표시됩니다. 준비된 카드는 학습 기록에 저장됩니다.
4. **3개 표현으로 말하기 연습 시작**을 누르면 순서대로 연습합니다. **원본 듣기 → 가리고 말하기 → 녹음·자가 점검 → 복습 저장 → 다음 표현**으로 이어집니다.
5. 같은 표현의 다른 상황을 연습하고 싶으면 **같은 표현, 다른 상황**을 누릅니다. 자동으로 만든 새 상황도 사용할 수 있습니다.

자동 자막 접근이 막히면 YouTube 스크립트나 TXT·SRT·VTT 자막을 가져옵니다. 이 경우에도 표현·뜻·상황은 직접 쓰지 않고 **이 자막으로 자동 학습 만들기**를 누릅니다. 자막 파일을 가져오면 자동 학습을 이어서 만듭니다. 시간 없는 자막은 전체 영상으로 연결하며 임의의 시간을 만들지 않습니다.

## 자동 추출의 두 방식

| 방식 | 선택 기준 | 가능한 일 |
|---|---|---|
| 로컬 AI 문맥 추출 | PC의 무료 AI가 준비된 경우 우선 사용 | 자막에서 재사용할 표현을 선정하고 한국어 뜻·설명·새 상황·영어 예문 작성 |
| 기본 자동 추출 | AI가 준비되지 않았거나 응답을 얻지 못한 경우 | 준비된 55개 표현의 설명과 새 상황을 원문과 자동 연결 |

두 방식은 결과 화면에 구분해 표시합니다. 기본 추출은 모든 문맥을 이해하는 AI가 아닙니다. 지원하는 표현이 없으면 무료 AI 준비를 안내하며 사용자에게 뜻을 작성하도록 요구하지 않습니다. 충분한 근거가 없을 때 표현 개수를 억지로 채우지 않습니다.

첨부한 화면의 자막에서는 아래 세 표현을 기본 추출로도 바로 공부할 수 있습니다. 오른쪽 예문은 학습용으로 새로 작성했으며 원본 영상의 발화가 아닙니다.

| 자동 선택 표현 | 의미 | 새 상황의 예문 |
|---|---|---|
| such a surprise | 정말 뜻밖인 일 / 큰 놀라움 | It was such a surprise to see my friend at the door. |
| to see how | 얼마나 / 어떻게 ~한지 보고·확인하다 | I was surprised to see how much the neighborhood had changed. |
| comes out | 작품·제품이 출시되다 / 공개되다 | Her new book comes out next month. |

## 무료 AI 최초 한 번 준비

앱의 **무료 AI로 문맥까지 자동 추출하기**를 펼칩니다.

1. **Ollama 설치**를 눌러 프로그램을 설치하고 실행합니다.
2. 앱으로 돌아와 **실행 상태 확인**을 누릅니다.
3. **무료 AI 준비 · 모델 다운로드**를 누릅니다. 완료되면 자동 추출을 사용합니다.

사용 모델은 Qwen 3.5 4B (`qwen3.5:4b`)이며 공식 배포 모델은 약 3.4GB입니다. Ollama 프로그램 설치 공간도 별도로 필요합니다. Windows 10 22H2 이상을 지원하며 실제 처리 속도는 PC의 메모리·GPU에 따라 달라집니다. [모델 정보](https://ollama.com/library/qwen3.5:4b), [Windows 설치 조건](https://docs.ollama.com/windows)

앱에는 API 키나 명령어를 입력하는 단계가 없습니다. 모델 다운로드는 **무료 AI 준비**를 직접 눌렀을 때만 시작합니다. 설치가 끝나면 자막의 문맥 분석은 이 PC에서 실행됩니다. OpenAI API나 클라우드 모델로 자동 전환하지 않으며 토큰별 API 요금이 발생하지 않습니다. 이 채팅의 ChatGPT가 앱에 상주하는 방식과는 다릅니다. [Ollama의 로컬 처리 안내](https://docs.ollama.com/faq)

AI 없이 `OPEN_ME.html`만 열어도 기본 자동 추출은 가능합니다. 문맥 AI는 이 ZIP의 무료 로컬 실행기로 서버를 열어 사용하세요. macOS/Linux는 `bash start_youtube_mac_linux.sh`입니다.

## 원문과 새 연습을 구분하는 방식

- 원본 영상의 자막, 영상 ID, 연결된 시간은 출처로 남깁니다.
- 추출 표현은 실제 자막에 있는 부분 문자열이어야 합니다. 모델이 만든 표현·인용·시간을 그대로 믿고 저장하지 않습니다.
- 한국어 뜻·상황과 새 영어 예문이 없는 불완전한 AI 결과는 걸러냅니다. 새 예문에 선택 표현이 실제 들어 있는지도 확인합니다.
- **원본 듣기**는 영상 속 화자의 소리를 재생합니다. **예시 답안**은 현재 말하기 상황을 위해 만든 예문을 보여줍니다. 새 상황에 답했는데 다른 사건을 다룬 원본 자막과 답을 비교하는 문제를 고쳤습니다.
- 구조·원문 대조 검사는 번역과 영어 표현의 자연스러움까지 보증하지 않습니다. 로컬 AI 작성 결과와 준비된 설명 모두 출처를 표시합니다.

로컬 모델에는 제한된 JSON 형식의 출력을 요청하고 결과를 별도로 검사합니다. 잘못된 출력에는 한 번만 로컬 재요청을 하며, 네트워크 연결 오류를 반복 재시도하지 않습니다. [Ollama 구조화 출력](https://docs.ollama.com/capabilities/structured-outputs)

## 중단·재추출·기록

**추출 대기 중단**을 누르면 늦게 도착한 결과를 학습 기록에 반영하지 않습니다. PC 안의 처리가 끝나기까지 잠시 걸릴 수는 있습니다. 처리 중 자막이나 구간이 달라져도 이전 결과를 다른 원문에 잘못 연결하지 않습니다.

동일한 영상·원문·표현을 다시 추출하면 카드를 중복 추가하지 않습니다. 기존 복습 날짜는 자동 추출만으로 바뀌지 않습니다. 원문이나 표현 설명을 본 직후의 연습은 힌트 연습으로 기록하며 복습 성공 횟수를 부풀리지 않습니다.

새 상황의 문제와 영어 예문은 백업에 함께 저장합니다. 구버전의 기록을 새 버전으로 가져올 수 있으며, 기존 원자료 32개와 학습 자료를 유지합니다. 신규 백업은 새 버전에서 사용하세요. 브라우저가 다르거나 주소·폴더가 바뀌면 설정의 기록 가져오기로 복원해야 할 수 있습니다.

## 검증 범위

자동 검사 **140개 통과**입니다.

| 검사 | 개수 | 주요 확인 사항 |
|---|---:|---|
| 기존 핵심 로직 | 33 | 복습 간격·인출 기록·백업·외부 교정 |
| 자막·유튜브 로직 | 9 | 시간·원문·인접 자막·사용자 카드 |
| 기본 자동 학습 | 6 | 첨부 자막의 3개 표현, 55개 예문의 표현 포함, 문맥 조건, 시간 없는 자료, 새 상황·예문 일치 |
| DOM 상호작용 | 57 | 입력 없이 자동 학습, 연습 순서, 원문·새 예문 구분, 재추출·중단·변경된 자막·백업 |
| 기존 무료·자막 서버 | 14 | 로컬 HTTP, 요청 제한, 모의 자막 서비스 |
| 로컬 AI·HTTP | 21 | 요청·출력 검증, 클라우드 모델 거절, 중복 처리, 제한된 재요청, 모델 다운로드 진행·실패 |

이 환경에 Ollama가 설치되어 있지 않아 **실제 모델의 추론 품질·속도와 사용자 PC에서의 설치 성공은 미검증**입니다. 모델의 답변과 다운로드 진행은 모의 응답을 사용했으며, 이를 실제 모델이 생성한 결과라고 표현하지 않습니다. 실제 YouTube 접속·브라우저 렌더링·기기 마이크·스피커·Windows/macOS 실행기 더블클릭도 미검증입니다.

유료 OpenAI API는 호출하지 않았습니다. 이전 유료 서버 검사 40개는 이번 합계에 넣지 않았습니다. 검사 로그와 실행 명령은 `validation_results.json`, `auto_*_test_results.txt`에 있습니다.
