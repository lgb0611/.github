Astra Speaking Lab 2.3 — 주요 표현 자동 학습

표현·한국어 뜻·말하기 상황을 직접 입력하지 않아도 됩니다.
기존 기록이 있다면 이전 앱에서 기록 내보내기를 먼저 하세요.
ZIP을 모두 압축 해제하고 기존 실행 창은 종료하세요.

[바로 사용]
1. start_youtube_windows.bat 실행 (Python 3.10~3.14 필요).
2. 유튜브 듣고 말하기 → 영상 링크 입력 → 이 영상으로 자동 학습 만들기.
3. 이미 자막이 있으면 이 구간의 주요 표현 자동 추출만 누르세요.
4. 자동으로 준비된 3개 표현으로 말하기 연습 시작.
5. 원본 듣기 → 가리고 말하기 → 녹음 → 자가 점검 → 복습 저장 → 다음 표현.

[무료 AI로 문맥까지 추출 — 최초 한 번]
앱의 무료 AI로 문맥까지 자동 추출하기 메뉴를 펼치세요.
① Ollama 설치 링크에서 프로그램을 설치하고 실행.
② 실행 상태 확인.
③ 무료 AI 준비 · 모델 다운로드.
준비 완료 뒤 자동 추출을 누르면 됩니다. 명령어·API 키 입력은 필요 없습니다.
모델은 약 3.4GB이며 프로그램 설치 공간도 별도로 필요합니다.
추론은 PC에서 실행되고 OpenAI API 요금이 들지 않습니다.

AI 설치 전에도 기본 자동 추출로 지원하는 표현은 바로 공부할 수 있습니다.
기본 목록에 없는 표현을 문맥에서 고르려면 무료 AI 준비가 필요합니다.
두 방식은 화면에 구분해서 표시합니다.

[자막을 가져오지 못하면]
YouTube 스크립트를 붙이거나 TXT/SRT/VTT 파일을 가져오세요.
이 자막으로 자동 학습 만들기를 누르면 표현·뜻·상황을 자동으로 만듭니다.
시간 정보가 없으면 전체 영상으로 연결합니다. 시간을 임의로 만들지 않습니다.

[다른 실행 방식]
OPEN_ME.html: 설치 없이 기존 자료와 기본 자동 추출 사용.
start_free_windows.bat: 추가 Python 패키지 없는 무료 로컬 실행.
macOS/Linux: bash start_youtube_mac_linux.sh
로컬 주소: http://127.0.0.1:8765/   종료: 실행 창에서 Ctrl+C.

[예문 소리가 안 날 때]
스피킹 연습 → 영어 음성 설정 → 목록 새로 읽기 → 음성 선택 → 음성 테스트.
유튜브 표현의 원래 소리는 영상 속 표현 먼저 듣기를 사용하세요.
녹음 파일은 녹음 저장으로 따로 보관하세요.
