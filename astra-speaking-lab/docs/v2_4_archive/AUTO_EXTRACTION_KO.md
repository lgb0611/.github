# 문장 청크 학습 — v2.4

짧은 숙어 3개를 고르던 흐름을 **영상 전체의 문장 청크 20개**로 바꿨습니다. 모델을 설치하지 않아도 원문 문장을 자동으로 준비합니다. 한국어 뜻을 직접 입력하는 단계는 없으며, 전체 문장 번역과 새 상황 생성은 PC의 무료 AI로 추가합니다.

## 영상에서 문장을 많이 준비하기

1. 이전 앱에서 기록을 내보내고 새 ZIP을 모두 압축 해제합니다. 이전 실행 창을 종료한 뒤 **start_youtube_windows.bat**을 실행합니다.
2. **유튜브 듣고 말하기 → 링크 → 이 영상으로 자동 학습 만들기**.
3. 기본 범위는 **영상 전체**, 한 묶음은 **20개**입니다. 10·40·60개를 선택하거나 최대 5분의 구간만 지정할 수 있습니다.
4. **다음 문장 추가**로 이어지는 문장을 더 담습니다. 준비된 카드는 10개씩 펼쳐 볼 수 있습니다.
5. **문장 순서대로 말하기**는 화면에 접힌 카드까지 모두 연습 순서에 넣습니다. 저장 한도는 모든 영상 합계 500개입니다.

자막을 한 줄씩 무조건 끊지 않습니다. 인접한 자막 조각을 연결하고 문장 경계에서 나눕니다. 구두점이 없는 긴 자동 자막은 긴 발화 청크로 표시합니다. 자동 자막의 문장 경계·인식 오류를 실제 음성과 비교할 수는 있습니다. 짧은 반응, 중복 문장, 명확히 연결어에서 끊긴 조각은 걸러냅니다. 문장의 문법적 완결성을 모든 경우에 판정하는 언어 모델은 아닙니다.

첨부 화면의 자막은 `such a surprise` / `to see how` / `comes out` 세 장 대신 다음 한 문장으로 묶습니다.

> Has that been such a surprise to see how like massive it's gotten just right when your album comes out.

원문의 `like` 등을 임의로 지워 자연스럽게 고친 인용인 것처럼 제시하지 않습니다. 영상 전체 자막에서 나머지 문장들을 이어서 가져와 연습량을 늘립니다. 자막이 짧으면 실제로 있는 문장 수만큼만 표시합니다.

## 한 문장으로 세 번 말하기

- **따라 말하기:** 「문장 듣기 · 기기 음성」이나 원본을 듣고 문장 전체를 따라 말합니다.
- **가리고 재현하기:** 「문장 가리기」를 누르고 방금 들은 장면을 떠올리며 말합니다. 필요하면 글자 없이 다시 듣습니다.
- **내 이야기로 바꾸기:** 사람·장소·시간·이유를 바꿔 말합니다. 무료 AI를 준비했다면 「AI 새 상황으로 말하기」로 자동 생성된 문제에 답할 수도 있습니다.

20문장을 각각 세 번 말하면 60번의 발화 연습입니다. 횟수는 연습 제안이며 앱이 실제 발화 횟수를 자동 감지하는 기능은 아닙니다. 녹음·자가 점검·복습 저장을 완료한 답변은 기존 기록에 남습니다. 따라 말한 직후의 답을 독립 인출 성공으로 계산하지 않습니다.

## 막힌 내장 재생을 거치지 않고 듣기

| 버튼 | 재생하는 소리 | 조건 |
|---|---|---|
| 문장 듣기 · 기기 음성 | 선택한 영어 음성으로 원문 문장 읽기 | 브라우저에 사용 가능한 영어 음성 필요 |
| YouTube 원본 시점 열기 | 원래 영상의 소리 | 새 탭에서 재생, 인터넷 및 해당 영상 접근 필요 |
| 내 파일로 구간 듣기 | 직접 연결한 영상·음성 파일 | 영상과 동일한 시작점의 파일, 브라우저가 지원하는 형식 |

내장 YouTube iframe을 학습의 필수 경로에서 제거했습니다. YouTube는 외부 재생을 허용하지 않는 영상 등에 별도 오류를 반환합니다. 앱이 영상의 공개·지역·재생 제한을 해제하지는 않습니다. 원본 링크는 자막 시작 시점으로 연결하지만 끝에서 자동으로 멈추지 않습니다. [YouTube 플레이어 오류 안내](https://developers.google.com/youtube/iframe_api_reference#onError)

앱 안에서 원래 소리를 반복하고 싶으면 **내 영상·음성 파일 연결**로 파일을 선택한 뒤 카드의 **내 파일로 구간 듣기**를 누르세요. 자막 시작 시점으로 이동하고 끝에서 일시정지합니다. 「이 구간 반복」과 속도 선택을 사용할 수 있습니다. 동영상 전체와 시작점이 다른 편집 파일은 시간이 맞지 않습니다. 시작 시점이 파일 길이를 벗어나면 재생 안내를 표시합니다. [브라우저 재생 위치 제어](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/currentTime)

파일은 브라우저 메모리에서 읽고 전송하지 않습니다. 다른 영상으로 바꾸거나 페이지를 닫으면 파일 연결을 해제합니다. 새로 열 때 파일을 다시 선택해야 합니다. 녹음 시작 전 앱의 원본 파일과 기기 음성을 멈춥니다. 별도로 연 YouTube 탭은 사용자가 일시정지해야 합니다.

여러 문장이 한 자막에 들어 있으면 같은 자막 구간으로 연결됩니다. 자막에 없는 단어별 시간을 추정해서 만들지 않습니다. 시간 없는 자막은 전체 영상 링크로 연결하고 파일 구간 반복을 끕니다. 기기 음성으로는 문장 단위로 들을 수 있습니다.

## 한국어 뜻과 새 상황 자동 추가

문장 추출 자체는 고정된 표현 목록에 제한되지 않습니다. AI를 쓰지 않은 카드는 **문장 통째로 듣고 다시 말하기**로 표시하며, 일부 포함 표현의 도움말을 제공할 수 있습니다. 이 도움말을 전체 문장 번역으로 표시하지 않습니다.

전체 문장 번역과 새 상황은 아래 순서로 준비합니다.

1. **한국어 뜻·새 상황도 자동으로 · 무료 AI 최초 1회 준비**를 펼칩니다.
2. **Ollama 설치** → 설치·실행 → 앱에서 **실행 상태 확인**.
3. **무료 AI 준비 · 모델 다운로드**.
4. **한국어 뜻·새 상황 자동 추가 · 무료 AI**. 명령어나 API 키를 입력하지 않습니다.

사용 모델은 `qwen3.5:4b`입니다. 모델 다운로드는 약 3.4GB이며 프로그램 설치 공간은 별도입니다. 실제 처리 속도는 PC에 따라 다릅니다. [모델 정보](https://ollama.com/library/qwen3.5:4b), [Windows 설치 안내](https://docs.ollama.com/windows)

네 문장씩 처리하고 완료한 묶음부터 저장합니다. 중단하면 늦게 도착한 응답을 반영하지 않습니다. 앞서 완료한 번역과 원문 문장은 그대로 남습니다. 다시 누르면 아직 뜻을 추가하지 못한 문장들을 처리합니다. 현재 자막과 다른 결과, 원문 문장 전체와 일치하지 않는 짧은 표현 응답은 거절합니다. 모델 출력을 검증하지만 번역·새 예문의 정확성까지 보증하지는 않습니다.

원문 회상은 원래 문장과 비교합니다. AI 새 상황은 그 상황에 맞춰 생성한 예문과 비교합니다. 새 상황에서도 영상의 사건을 그대로 따라 말하도록 강요하지 않습니다. 모델은 구조를 재사용하며 세부 내용을 바꿀 수 있습니다.

## 기록·실행·검증

기존 자료 32개와 학습 기록 형식을 유지합니다. 큰 문장과 긴 연습 순서를 담은 새 백업은 v2.4에서 복원하세요. 기존 버전에는 문장 길이·개수 제한이 있어 새 백업을 읽지 못할 수 있습니다. 주소·브라우저가 바뀌면 기록 가져오기로 복원합니다.

자동 검사 결과와 실행 명령은 **validation_results.json**, **chunk_node_test_results.txt**, **chunk_python_test_results.txt**에 있습니다. 문장 분리·긴 순서·중복·재열기·AI 중단·일부 실패·기기 음성 연결·파일 범위·반복·녹음 시작 시 정지를 검사했습니다.

기기 음성 및 미디어 이벤트는 DOM 모의 환경에서 검증했습니다. 실제 YouTube 재생, Windows의 스피커·마이크·코덱, 로컬 AI의 실제 설치·생성 품질·속도는 이 환경에서 확인하지 못했습니다. 유료 API는 호출하지 않았습니다. 기존 v2.3 자료는 **v2_3_archive/**에 보관합니다.
