# 유료 API 없는 학습 — v2.4

문장 청크를 기본 20개씩 추출하고 기기 음성·녹음·복습으로 연결합니다. 한국어 뜻과 새 상황은 PC의 무료 AI로 자동 추가할 수 있습니다. 모델이 없어도 사전에 없는 긴 문장을 추출해 말하기 연습을 할 수 있습니다. 원본은 YouTube의 해당 시점 링크나 직접 연결한 파일로 듣습니다. 자세한 안내는 AUTO_EXTRACTION_KO.md에 있습니다.

무료 모드는 매번 기본이며 유료 OpenAI 요청을 차단합니다. 자동 추출만으로 녹음·학습 기록을 외부 AI에 보내지 않습니다. 모델 설치 때는 다운로드를 위해 인터넷을 사용하고, 설치 후 문맥 추출은 PC에서 처리합니다. 자막과 YouTube 영상에는 인터넷이 필요합니다.

[자동 학습·설치·검증 안내](AUTO_EXTRACTION_KO.md)와 [전체 사용법](../README_KO.md)을 참고하세요. 자동 검사 153개가 통과했으며 실제 모델 추론은 미검증입니다. 이전 버전의 검증은 각 보관 폴더에 있으며 이번 합계에 과거 검사를 더하지 않았습니다.
