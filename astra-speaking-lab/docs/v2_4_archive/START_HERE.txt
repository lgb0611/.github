Astra Speaking Lab 2.4 — 문장 청크로 많이 말하기

먼저 이전 앱에서 「기록 내보내기」로 백업하세요.
새 ZIP을 모두 압축 해제하고 이전 실행 창은 종료하세요.
start_youtube_windows.bat을 실행하면 새 버전이 열립니다.

1. 유튜브 듣고 말하기 → 영상 링크 → 이 영상으로 자동 학습 만들기.
2. 영상 전체에서 문장 청크 20개를 준비합니다. 10·40·60개도 선택 가능.
3. 「다음 문장 추가」로 나머지 문장을 계속 가져올 수 있습니다.
4. 각 문장에서 「문장 듣기 · 기기 음성」 → 따라 말하기 → 「문장 가리기」 → 다시 말하기.
5. 사람·장소·이유를 내 이야기로 바꿔 한 번 더 말해 보세요.
6. 「문장 순서대로 말하기」 → 녹음 → 자가 점검 → 복습 저장 → 다음 표현.

기존의 짧은 표현 대신 문장 전체를 추출합니다.
구두점이 없는 자동 자막은 긴 발화 청크로 묶습니다.
짧은 영상은 실제 문장 수만큼만 준비하며 중복·미완성 조각을 걸러냅니다.
한국어 뜻이나 표현을 직접 입력할 필요는 없습니다.

[듣기가 바뀌었습니다]
문장 듣기: 기기의 영어 음성으로 읽습니다. 원래 화자의 목소리는 아닙니다.
YouTube 원본: 해당 시작 시점의 새 탭을 엽니다. 그곳에서 재생을 누르세요.
YouTube 페이지는 끝 시간에서 자동으로 멈추지 않습니다.
내 영상·음성 파일 연결: 영상과 시작점이 같은 파일을 직접 선택하면
앱에서 자막 구간 듣기·반복·속도 조절이 됩니다. 파일을 업로드하지 않습니다.
페이지를 닫으면 파일 연결은 해제됩니다.
기기 소리가 없으면 유튜브 탭의 「기기 음성 설정」에서 영어 음성을 확인하세요.

[한국어 뜻·새 상황도 자동으로 — 선택]
원문 문장 추출·듣기·말하기에는 모델 설치가 필요 없습니다.
문장 전체의 한국어 뜻과 새 상황 생성에는 PC의 무료 AI가 필요합니다.
「한국어 뜻·새 상황도 자동으로 · 무료 AI 최초 1회 준비」를 펼쳐
① Ollama 설치·실행 → ② 실행 상태 확인 → ③ 무료 AI 준비.
준비 뒤 「한국어 뜻·새 상황 자동 추가 · 무료 AI」를 누르세요.
4문장씩 처리하며 중단·실패해도 완료된 뜻과 문장 연습은 남습니다.
API 키·유료 호출 없이 동작합니다. 모델은 약 3.4GB, 프로그램 공간은 별도입니다.

[자동 자막 접근이 막히면]
YouTube 스크립트를 붙이거나 TXT/SRT/VTT를 가져오세요.
자막이 없거나 공개 접근이 차단된 영상에서는 링크만으로 추출할 수 없습니다.
시간 없는 자막은 전체 영상으로 연결하고 기기 음성으로 문장을 들을 수 있습니다.

[실행]
Windows: start_youtube_windows.bat (Python 3.10~3.14, 최초 자막 패키지 설치).
macOS/Linux: bash start_youtube_mac_linux.sh
OPEN_ME.html: 설치 없이 기존 자료와 문장 추출·기기 음성·내 파일 재생 사용.
start_free_windows.bat: 추가 패키지 없는 무료 로컬 실행.
주소: http://127.0.0.1:8765/   종료: 실행 창에서 Ctrl+C.
