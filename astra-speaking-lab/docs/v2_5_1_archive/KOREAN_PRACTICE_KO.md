# 한국어를 보고 영어로 말하기 — v2.5.1

문장마다 합성 음성으로 듣고, 한글 문장이나 문단을 보고 영어로 말하도록 바꿨습니다. 문장 추출 수는 기본 20개이며 10·40·60개 묶음과 다음 묶음 추가를 유지합니다.

## 해당 문장만 듣기

각 추출 카드의 **음성 듣기 · 이 문장만**은 그 카드의 영어 문장 하나만 합성 음성으로 읽습니다. YouTube 이동·영상 구간 재생을 실행하지 않습니다. 다른 문장을 누르면 이전 음성을 취소하고 새 문장을 읽습니다. 카드 위에서 목소리와 속도를 고르고 **음성 정지**를 누를 수 있습니다. 온라인 음성만 있으면 같은 곳의 **온라인 영어 음성 사용**을 체크하세요. 방금 듣기를 요청한 문장이 있으면 체크 직후 재생합니다. **음성 테스트**로 소리를 확인할 수 있습니다.

스피킹 화면에서도 표현마다 **이 문장 음성 듣기**가 있습니다. 한 문장 문제의 **영어 답안 음성 듣기**는 그 문제의 예문 하나를, 문단 문제의 **영어 예시 문단 음성 듣기**는 해당 문단을 읽습니다. 원문 발화와 연습용 새 상황의 영어 답안을 혼동하지 않도록 각각 맞는 텍스트를 사용합니다.

소리는 브라우저의 음성 합성 기능으로 재생합니다. 기기 영어 음성이 기본이며 온라인 음성은 설정에서 직접 허용했을 때만 선택합니다. 생성된 소리는 원래 화자의 목소리가 아닙니다. 사용 가능한 영어 음성이 없으면 목소리를 설치하거나 음성 설정을 확인해야 합니다. [브라우저 음성 합성](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance)

원본 링크와 직접 연결한 파일은 접힌 **원본 자료 확인**에 남아 있습니다. 일반 문장 듣기는 이 메뉴를 거치지 않습니다.

## 한 문장씩 말하기

1. 영상을 연결해 문장을 추출하면 한국어 버전도 자동 준비합니다.
2. **한글 보고 한 문장씩 말하기** 또는 카드의 **녹음하고 연습**을 누릅니다.
3. 한국어 문장이 처음부터 화면 위쪽에 보입니다. 영어 표현과 예시 답안은 숨깁니다.
4. 한국어 내용을 영어로 말하고 녹음·자가 점검합니다. 음성이나 영어 답안을 확인하면 힌트 사용으로 기록합니다.
5. 복습 평가를 저장한 뒤 다음 문장으로 이동합니다.

한국어는 “이런 상황에서 말해 보세요”라는 일반 안내 대신 실제로 영어로 말할 내용을 제시합니다. 원래 작성된 한국어 문제가 있는 기본 자료는 그대로 사용하며, 새 자막 문장은 전체 의미를 번역합니다. 자동 번역은 문맥·말투·인식 오류 때문에 틀릴 수 있습니다.

## 여러 문장으로 한글 문단 말하기

추출 카드에서 **문단에 활용**을 2~5개 선택하고 화면 하단에 나타나는 **선택한 N문장으로 문단 연습**을 누르세요. 고르지 않으면 현재 자료에서 학습 기록이 있는 문장부터 3개를 선택합니다. 스피킹 화면의 같은 버튼과 표현 서재의 여러 항목 선택으로도 시작할 수 있습니다.

| 준비 상태 | 제시하는 한글 문단 |
|---|---|
| 무료 로컬 AI 준비 완료 | 선택한 모든 학습 문장을 활용할 수 있는 새로운 가상 상황 문단 |
| 무료 AI 미준비 또는 생성 실패 | 선택한 원문 문장들의 한국어 내용을 순서대로 이어 놓은 문단 |

새 상황 문단은 학습 문장의 유용한 구조를 사용하면서 세부 내용을 바꿉니다. 원문 이어 말하기는 원래 내용의 재현 연습입니다. 원문 이어 말하기에 자동으로 새로운 사건을 덧붙이거나 새로운 상황을 생성했다고 표시하지 않습니다.

한국어 문단이 먼저 나타나고 영어 답안은 가려집니다. 학습한 문장들을 활용해 영어 문단으로 말한 후 예시와 비교합니다. **다음 문장 묶음으로 문단 연습**으로 이어서 연습할 수 있습니다. 문단 한 번의 답변에 사용한 모든 카드의 복습 평가를 함께 저장합니다. 단문 연습 순서와 섞이지 않도록 문단을 시작하면 단문 순서는 종료합니다.

새 문단에서는 카드마다 학습 문장의 어느 구절을 재사용했는지, 한글 문제와 영어 예시의 어디에 대응하는지 검사합니다. 누락된 카드·존재하지 않는 구절·다른 예시 인용은 거절합니다. 이 검사는 번역이나 문단의 자연스러움을 완전히 보장하지는 않습니다.

## 한국어를 자동으로 준비하는 방법

지원되는 데스크톱 Chrome에서는 브라우저의 기기 내 영어→한국어 번역을 먼저 사용합니다. 첫 사용에 언어 파일 다운로드가 필요할 수 있으며 브라우저가 사용자 클릭을 요구하면 **한국어 준비**를 누르세요. 지원 여부는 실행할 때 확인합니다. [Chrome의 기기 내 번역과 언어 지원](https://developer.chrome.com/docs/ai/translator-api)

브라우저 번역을 사용할 수 없으면 준비된 무료 로컬 AI를 사용합니다. 둘 다 준비되지 않았다면 한국어를 생성했다고 표시하지 않고 준비 방법을 안내합니다. 이미 추출한 영어 문장의 음성 듣기는 계속 사용할 수 있습니다.

무료 AI는 앱의 **무료 AI 준비 안내 → Ollama 설치·실행 → 상태 확인 → 무료 AI 준비** 순서로 설정합니다. `qwen3.5:4b` 모델을 사용하며 다운로드는 약 3.4GB, 프로그램 공간은 별도입니다. OpenAI API 키나 유료 호출은 사용하지 않습니다. 실제 처리 속도는 PC에 따라 다릅니다. [모델 정보](https://ollama.com/library/qwen3.5:4b)

완료한 한국어는 해당 영어 원문과 함께 저장합니다. 동일한 문장은 다시 번역하지 않고, 원문이 다른 번역 결과는 연결하지 않습니다. 준비를 중단해도 완료한 한국어와 기존 학습 기록은 남습니다. 페이지·영상·원문이 바뀐 후 늦게 도착한 결과는 적용하지 않습니다.

## 기존 기록과 검증 범위

이전 앱에서 기록 내보내기로 백업한 뒤 새 버전을 실행하세요. v1~v2.4 기록을 읽으며 한국어 번역과 문단 연습이 추가된 백업은 v2.5에서 사용하세요. 주소·브라우저가 바뀌면 기록 가져오기로 복원합니다. 원자료 32개를 그대로 보존합니다.

이번 자동 검사 로그와 실행 명령은 **validation_results.json**, **audio_fix_node_test_results.txt**에 있습니다. 이전 v2.5 검사는 **v2_5_archive/**에 있습니다. 실제 목소리 재생과 브라우저 번역 결과·다운로드, 로컬 AI의 문단 품질·생성 속도, Windows 마이크·스피커는 이 환경에서 검증하지 못했습니다. 음성·번역·모델 출력은 모의 응답과 이벤트로 검증합니다. 유료 API 호출은 하지 않습니다.
