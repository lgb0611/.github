Astra Speaking Lab 2.5 — 한국어를 보고 영어로 말하기

이전 앱에서 기록 내보내기로 백업한 뒤 새 ZIP을 모두 압축 해제하세요.
이전 실행 창은 종료하고 start_youtube_windows.bat을 실행하세요.

[문장별 음성 듣기]
유튜브 듣고 말하기 → 영상 링크 → 이 영상으로 자동 학습 만들기.
각 카드의 「음성 듣기 · 이 문장만」을 누르면 해당 영어 문장만 읽습니다.
YouTube를 열지 않고 앱 안에서 합성 음성으로 재생합니다.
다른 문장을 누르면 이전 재생은 멈춥니다. 위에서 목소리·속도·정지를 조절하세요.
원본 링크와 내 파일 재생은 접힌 「원본 자료 확인」에 있습니다.

[한 문장씩 한국어 → 영어]
문장을 추출하면 한국어 버전도 자동으로 준비합니다.
「한글 보고 한 문장씩 말하기」 또는 카드의 「녹음하고 연습」을 누르세요.
처음부터 한국어 문장이 보이고 영어 답안은 가려져 있습니다.
한국어를 영어로 말하기 → 녹음 → 자가 점검 → 복습 저장 → 다음 문장.

[여러 문장으로 한글 문단]
각 카드에서 「문단에 활용」을 2~5개 선택합니다.
「여러 문장으로 한글 문단 연습」을 누르세요.
선택하지 않으면 학습한 문장부터 3개를 자동으로 고릅니다.
한국어 문단이 먼저 보입니다. 학습한 문장들을 활용해 영어로 이어 말하세요.
영어 예시는 「예시 답안 보기」 또는 음성 듣기로 확인합니다.
「다음 문장 묶음으로 문단 연습」으로 다른 문장도 계속 연습하세요.
표현 서재에서 여러 문장을 고른 뒤 「선택 표현 바로 연습」을 눌러도 됩니다.

[한국어 준비 — 처음 한 번]
지원되는 데스크톱 Chrome에서는 기기 내 번역으로 한국어를 만듭니다.
첫 사용에는 브라우저가 번역용 언어 파일을 다운로드할 수 있습니다.
자동 준비가 안 되면 「한국어 준비」를 한 번 눌러 주세요.
그 뒤 완료된 한국어는 학습 기록에 저장되어 다시 번역하지 않습니다.
브라우저 번역을 지원하지 않으면 준비된 무료 로컬 AI를 사용합니다.

[새로운 상황의 문단 — 무료 AI]
무료 AI 준비 안내 → Ollama 설치·실행 → 실행 상태 확인 → 무료 AI 준비.
API 키나 유료 호출 없이 동작합니다. 모델 다운로드는 약 3.4GB입니다.
AI가 준비되어 있으면 학습한 여러 문장으로 새로운 상황의 한글 문단을 만듭니다.
없거나 생성에 실패하면 학습 문장들의 한국어 내용을 이어 말하는 문단을 사용합니다.
화면에서 두 문단의 출처를 구분합니다. 한국어를 직접 작성할 필요는 없습니다.

[소리가 없으면]
문장 카드 위 「목소리 새로 읽기」와 목소리 선택을 확인하세요.
기기 음성 설정에서 음성 테스트를 할 수 있습니다.
Windows에 영어 음성이 없으면 영어 음성을 추가해야 합니다.
브라우저 온라인 음성은 설정에서 직접 허용할 때만 사용합니다.

[실행]
Windows: start_youtube_windows.bat (Python 3.10~3.14, 최초 자막 패키지 설치)
macOS/Linux: bash start_youtube_mac_linux.sh
주소: http://127.0.0.1:8765/    종료: 실행 창에서 Ctrl+C
OPEN_ME.html에서도 기본 자료와 음성 읽기는 됩니다. 한국어·자막 기능은 로컬 실행 권장.
자동 자막이 차단되면 TXT/SRT/VTT나 스크립트를 가져오세요.
