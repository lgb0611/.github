# 현재 문장의 한국어 뜻 유지 · v2.6.1

전체 대본 재생 중, 카드로 추출했던 문장은 한국어가 나타나고 카드에 없는 문장은 한국어 줄 자체가 숨겨졌습니다. 이전 재생기가 카드의 번역만 조회했기 때문입니다.

이제 대본 문장을 정확한 영어 원문과 연결한 별도 번역 캐시에 저장합니다. 카드 추출 수·카드 저장 한도와 관계없이 재생할 문장의 뜻을 준비합니다. 짧은 대답이나 같은 문장의 반복도 포함합니다. 기존 카드에 정확히 일치하는 번역이 있으면 먼저 사용합니다.

## 바뀐 재생 순서

1. 현재 문장의 저장된 뜻을 확인합니다. 있으면 즉시 영어 아래에 표시하고 읽습니다.
2. 뜻이 없으면 같은 자리에 한국어 준비 상태를 표시하고 자동으로 번역합니다.
3. 한국어가 준비되면 표시한 뒤 해당 영어 문장의 음성을 시작합니다.
4. 다음 최대 5문장을 미리 번역합니다. 다음 문장으로 넘어갈 때도 해당 문장의 뜻이 준비된 뒤 읽습니다.

번역이 빠르지 않은 환경에서는 첫 재생이나 미리 번역하지 못한 문장에서 잠시 기다릴 수 있습니다. 이전 문장의 한국어를 새 영어 아래에 계속 표시해 의미를 잘못 연결하지 않습니다. 전체 대본을 먼저 모두 번역할 때까지 기다리는 방식도 아닙니다.

현재 문장과 준비된 한국어는 일시정지·반복·정지 후에도 남아 있습니다. 일시정지 중 번역이 완료되어도 음성을 임의로 시작하지 않습니다. 이전·다음 문장으로 이동하면 새 문장에 맞는 한국어를 표시합니다. 정지·다른 자료·녹음 시작으로 중단된 번역이 늦게 도착해도 화면이나 재생을 되살리지 않습니다.

## 번역과 재시도

현재 앱의 브라우저 번역 또는 무료 로컬 번역을 사용합니다. 첫 언어 파일 준비가 필요한 경우를 위해 재생 버튼을 누른 시점에 번역기를 준비합니다. Chrome의 기기 번역은 언어 파일을 필요에 따라 내려받고 요청을 순차 처리합니다. [Chrome Translator 안내](https://developer.chrome.com/docs/ai/translator-api)

번역을 연결하지 못했거나 결과가 한국어 문장으로 확인되지 않으면 한국어 줄을 숨기지 않고 이유와 **한국어 다시 준비** 버튼을 표시합니다. 오류 문장의 음성을 자동으로 계속 재생하지 않습니다. 설정을 준비한 뒤 다시 시도하거나 이전·다음 문장으로 이동할 수 있습니다. 한 문장의 실패가 뒤 문장의 정상적인 브라우저 번역까지 막지는 않습니다.

재시도는 현재 문장을 다시 준비합니다. 일시정지 중 누르면 뜻만 준비하고 **이어 듣기**를 기다립니다. 이미 저장한 다른 문장의 번역은 유지합니다. 읽을 영어와 일치하지 않는 번역 응답은 저장하거나 표시하지 않습니다. 이 일치 검사는 번역의 모든 의미·자연스러움을 보장하는 검사는 아닙니다.

## 저장과 이전 기록

카드 번역을 먼저 재사용하며, 카드가 없는 대본 문장의 번역은 별도로 브라우저 기록에 저장합니다. 반복 재생과 앱 재실행에서 정확히 같은 영어 문장의 뜻을 재사용합니다. 같은 문장의 반복마다 번역을 다시 요청하지 않습니다.

새 캐시는 기록 내보내기·가져오기에 포함됩니다. 기존 v2.6 이하 기록도 읽을 수 있습니다. 새 대본 캐시까지 복원하려면 v2.6.1을 사용하세요. 캐시는 최대 6,000문장, 영어·한국어 합계 100만 글자까지 유지하고 초과하면 오래 저장한 항목부터 비웁니다. 학습 카드와 복습 기록을 삭제하는 동작은 아닙니다. 저장 공간이 부족하면 기존 저장 안내를 표시하며 그 실행 중 준비한 뜻은 메모리에 남습니다.

## 검증 범위

- 116문장 중 55번째 문장을 골라, 20개 카드에 없던 문장의 한국어가 준비된 다음 음성을 시작하는지 검사했습니다.
- 65문장 전체를 재생하며 모든 현재 문장 아래에 해당 한국어가 있고, 한국어 줄이 숨겨지지 않는지 검사했습니다.
- 다음 문장 미리 번역, 준비 중 안내, 일시정지 중 완료, 원문 변경·정지·이동 뒤 늦은 결과 차단을 검사했습니다.
- 번역 불가·시간 초과·다른 원문 응답·한 문장 실패 후 다음 문장·재시도·캐시 백업·복원을 검사했습니다.
- 기존 음성 재생·구간 반복·한국어 카드·문단 연습의 자동 검사도 실행했습니다.

음성과 번역 응답은 모의 환경에서 검증했습니다. 사용자의 실제 PC에서 언어 파일 다운로드, 음성 출력, 번역 품질과 처리 속도를 직접 확인한 것은 아닙니다. 유료 API를 호출하지 않았습니다. 수치와 명령은 **validation_results.json**에 있습니다.
