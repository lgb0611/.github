# 대본 전체 듣기와 구간 반복 · v2.6

영상의 자막을 합성 음성으로 이어 듣고, 원하는 문장이나 여러 문장을 반복할 수 있습니다. 유료 API 키가 필요하지 않습니다.

## 전체 대본을 한 번에 듣기

1. **유튜브 듣고 말하기**에서 영상 링크로 자막을 불러옵니다. 자동 가져오기가 안 되면 기존 자막 붙여넣기·파일 가져오기를 사용할 수 있습니다.
2. **영어 합성 음성**에서 목소리와 속도를 고릅니다. 처음에는 **음성 테스트**로 출력 장치를 확인하세요. 온라인 음성만 있으면 바로 아래 **온라인 영어 음성 사용**을 체크합니다.
3. **대본 전체 재생**을 누릅니다. 현재 문장, 전체 위치, 진행 막대가 나타납니다.
4. **일시정지 / 이어 듣기**, **이전 / 다음 문장**, **정지**로 조절합니다. 전체 재생 버튼을 다시 누르면 첫 문장부터 시작합니다.

전체 재생은 실제로 불러온 자막 전체를 사용합니다. 카드 추출 수나 추출 범위를 줄여도 대본 재생 범위는 줄지 않습니다. 짧은 대답과 같은 문장의 반복도 원문 순서대로 읽습니다. 자막 조각은 문장 경계로 합치고 나누며 긴 발화는 읽기 가능한 청크로 나눕니다. 순수한 음악·박수 표기만 있는 행은 건너뜁니다. 자막에서 누락된 말이나 영상의 원래 목소리·효과음을 복원하는 기능은 아닙니다.

학습 카드를 추출하지 않고 **자막만 읽기**를 해도 전체 재생을 사용할 수 있습니다. 시간이 없는 TXT도 가능합니다. 카드용 한국어 번역은 기존처럼 자동으로 준비하며, 재생기의 현재 문장은 저장된 한국어 뜻이 있는 경우 함께 표시합니다.

## 원하는 한 문장 반복

학습 카드의 **이 문장 반복**, 또는 **대본 문장 보기 · 반복 구간 선택**을 펼친 뒤 해당 행의 **이 문장 반복**을 누릅니다. 그 문장이 시작·끝 문장으로 선택되고 바로 반복합니다. 기본은 **3회**, 문장을 읽고 **1초** 쉰 뒤 다음 회차를 시작합니다.

원하는 반복 횟수와 쉬는 시간을 먼저 고를 수도 있습니다. 목록의 **이 문장 듣기**는 한 번만 읽습니다. 전체 자막이 남아 있지 않은 과거 영상의 카드는 해당 자막을 다시 불러와야 반복 범위를 고를 수 있습니다.

## 여러 문장을 구간 반복

1. **반복 시작 문장**과 **반복 끝 문장**을 고릅니다. 목록의 **구간 시작 / 구간 끝** 버튼으로 골라도 됩니다.
2. **반복 횟수**를 1·2·3·5·10회 또는 계속 반복으로 고릅니다.
3. **반복 사이 쉬기**를 0·1·2·3·5초 중에서 고릅니다.
4. **선택 구간 반복**을 누릅니다. 시작과 끝 문장 모두 포함해 순서대로 읽습니다.

예를 들어 4번~6번 문장을 3회, 2초 간격으로 설정하면 4→5→6을 읽고 2초 쉰 뒤 다시 4→5→6으로 이어갑니다. 3회차의 6번 문장이 끝나면 멈춥니다. 쉬는 시간은 문장마다가 아니라 선택 구간을 한 번 다 읽을 때마다 적용됩니다. 전체 재생은 이 반복 설정과 관계없이 한 번만 읽습니다.

일시정지는 문장을 읽는 중과 회차 사이 쉬는 시간 모두에 적용됩니다. 브라우저의 음성 일시정지 동작을 사용할 수 없으면 이어 듣기 때 현재 문장부터 다시 읽는다고 안내합니다. 일시정지 상태에서 이전·다음 문장으로 이동하면 바로 소리가 나지 않고 이어 듣기를 기다립니다.

## 대본 목록과 현재 위치

대본 목록은 40문장씩 표시합니다. 앞·다음 40문장 버튼으로 이동하고 원하는 문장의 시작·끝을 고릅니다. 목록에서 선택한 구간과 현재 재생 문장은 강조됩니다. **재생 중인 문장 따라가기**가 켜져 있으면 재생 위치에 맞춰 목록 페이지가 이동합니다. 목록을 직접 넘기면 따라가기가 꺼져 원하는 부분을 고를 수 있습니다. **현재 문장으로**를 누르면 재생 위치로 돌아갑니다.

한국어를 보고 말하기 연습은 기존 방식대로 영어를 가립니다. 대본을 직접 보거나 합성 음성으로 들은 학습 카드는 도움을 받은 연습으로 기록해 독립 회상 성적을 부풀리지 않습니다.

## 재생이 멈추는 경우

- **정지**, 다른 문장 듣기, 음성 테스트 또는 녹음을 시작하면 기존 반복을 중단합니다.
- 화면 이동, 다른 영상 연결, 대본 편집, 반복 범위·횟수·간격·목소리·속도 변경 시에도 기존 재생을 멈춥니다. 새 설정으로 재생 버튼을 다시 누르세요.
- 번역·자막 가져오기 등 대기 작업이 시작되면 음성을 멈춥니다. 작업 완료 후 재생 버튼을 다시 사용할 수 있습니다.
- 음성을 시작하지 못하거나 연결 오류가 발생하면 반복을 멈추고 안내합니다. 오류 상태에서 무한히 재시도하지 않습니다.

온라인 음성 허용을 기다리고 있었다면 체크 직후 요청했던 전체 대본 또는 반복 구간을 시작합니다. 대기 중 정지하거나 다른 화면으로 이동했다면 나중에 허용해도 재생하지 않습니다. 온라인 음성은 인터넷이 필요하고 읽을 문장이 브라우저의 음성 서비스로 전송될 수 있습니다.

## 검증 범위

문장 순서·전체 대본·포함 구간·횟수·무한 반복 중단·쉬는 시간·일시정지·이전/다음·권한 허용·소스 변경을 자동화한 DOM 테스트로 확인했습니다. 실제 PC의 소리 출력과 각 브라우저의 음성 품질은 확인하지 못했습니다. 음성 기능은 [SpeechSynthesis 일시정지](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/pause), [이어 듣기](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/resume), [발화 완료 이벤트](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/end_event)를 사용합니다.
