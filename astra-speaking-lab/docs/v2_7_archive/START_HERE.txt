[추가한 PDF 두 개로 바로 공부하기]
압축을 풀고 OPEN_ME.html을 Chrome 또는 Edge로 여세요.
상단 ‘인터뷰 자료’ → JENNIE 또는 Elon Musk → 이 자료로 공부하기.
한국어 뜻이 이미 포함되어 있습니다. API 키나 번역 모델 설치가 필요 없습니다.

JENNIE: 원자료 연습 항목 55개 → 문장별 듣기 60개, 표현표 19개.
Elon Musk: 39개 주제 → 문장·짧은 응답·상황 설명 363개.
각 자료에 새 상황 응용 문단도 5개씩 있습니다.

문장 듣기 / 전체 재생 / 문장 구간 반복 → 한글 보고 말하기 → 자가 점검·복습.
‘문단에 활용’을 2~5개 선택하고 선택 문장으로 한글 문단 말하기를 누르세요.
아래 ‘응용 문단’에서는 미리 준비한 새 상황으로 연습할 수 있습니다.

‘온라인 영어 음성 사용’을 확인하세요. 원래 출연자의 음성은 아닙니다.

http://127.0.0.1:8765/ 로 여세요. 기록 이동은 설정의 내보내기·가져오기를 사용하세요.

[이번 수정: 현재 문장 아래 한국어 뜻이 사라지던 문제]
학습 카드에 없는 대본 문장도 한국어로 자동 번역해 표시합니다.
처음 듣는 문장은 한국어 뜻을 준비한 뒤 음성을 시작합니다.
다음 최대 5문장도 미리 번역해 재생 중 기다림을 줄입니다.
뜻이 없는 문장에서 한국어 영역을 숨기지 않습니다.
일시정지·반복 재생·이전/다음 문장 이동에도 해당 뜻을 표시합니다.
완료한 번역은 저장해 반복하거나 앱을 다시 열 때 재사용합니다.
번역 중에는 준비 안내, 실패할 때만 「한국어 다시 준비」를 표시합니다.
지원되는 Chrome의 번역 기능 또는 준비된 무료 로컬 AI가 필요합니다.
유료 API를 연결할 필요는 없습니다.
자세한 수정 내용: docs/CURRENT_SENTENCE_KOREAN_FIX_KO.md

[대본 전체 재생 · 구간 반복]
유튜브 듣고 말하기에서 자막을 불러온 뒤 「대본 전체 재생」을 누르세요.
추출 카드 20개뿐 아니라 불러온 대본의 모든 발화를 합성 음성으로 이어 읽습니다.
한 문장은 카드 또는 대본 목록의 「이 문장 반복」을 누르세요.
여러 문장은 시작·끝 문장을 고른 뒤 「선택 구간 반복」을 누르세요.
대본 목록에서 「구간 시작 / 구간 끝」으로도 고를 수 있습니다.
기본은 3회 반복, 한 구간을 다 읽은 뒤 1초 쉬기입니다.
1·2·3·5·10회 / 계속 반복과 0·1·2·3·5초 간격을 선택할 수 있습니다.
일시정지 / 이어 듣기, 이전 / 다음 문장, 정지 버튼을 사용할 수 있습니다.
목소리와 속도는 바로 위 영어 합성 음성 설정을 함께 사용합니다.
온라인 음성만 있으면 「온라인 영어 음성 사용」을 체크하세요.
앱의 유료 API를 사용하거나 YouTube 창을 열지 않습니다.
대본을 바꾸거나 녹음·다른 음성을 시작하면 이전 반복은 멈춥니다.
자세한 안내: docs/TRANSCRIPT_PLAYER_KO.md

[한국어 뜻 자동 표시]
문장을 추출하면 별도 버튼 없이 한국어 번역도 시작합니다.
한 문장씩 번역되는 즉시 영어 바로 아래에 한국어 뜻을 표시합니다.
묶음 전체가 끝날 때까지 기다렸다가 뜻을 보여 주지 않습니다.
저장한 영상 학습 화면을 다시 열거나 문장 더 보기를 누르면 빠진 뜻만 자동으로 채웁니다.
이미 저장한 한국어 뜻은 처음부터 표시됩니다. 다시 번역하지 않습니다.
번역 중에는 현재 문장의 진행 상태와 전체 완료 개수를 보여 줍니다.
일부 문장이 실패해도 뒤의 문장은 계속 번역합니다.
번역 기능 연결 실패나 중단 시에만 다시 시도 / 이어 번역 버튼을 표시합니다.
지원되는 Chrome의 번역 기능 또는 준비된 무료 로컬 AI가 필요합니다.
번역용 언어 파일은 첫 사용에 다운로드할 수 있습니다. 유료 API는 사용하지 않습니다.

[이전 수정: 음성 듣기와 문단 선택]
온라인 음성만 있는 PC에서는 카드 위 「온라인 영어 음성 사용」을 체크하세요.
음성 듣기를 먼저 눌렀다면 체크 직후 그 문장을 읽습니다.
「음성 테스트」로 소리를 확인할 수 있습니다. 같은 오류 문구의 중복 표시는 제거했습니다.
문단에 활용을 체크하면 카드 색상과 화면 하단의 선택 개수가 바뀝니다.
2~5개를 선택한 뒤 하단 「선택한 N문장으로 문단 연습」을 누르세요.
한국어 문단을 준비하고 스피킹 화면으로 이동합니다. 영어 답안은 가려 둡니다.
체크는 사용할 문장을 고르는 단계이며, 문단 생성은 하단 버튼으로 시작합니다.

[문장별 음성 듣기]
유튜브 듣고 말하기 → 영상 링크 → 이 영상으로 자동 학습 만들기.
각 카드의 「음성 듣기 · 이 문장만」을 누르면 해당 영어 문장만 읽습니다.
YouTube를 열지 않고 앱 안에서 합성 음성으로 재생합니다.
다른 문장을 누르면 이전 재생은 멈춥니다. 위에서 목소리·속도·정지를 조절하세요.
원본 링크와 내 파일 재생은 접힌 「원본 자료 확인」에 있습니다.

[한 문장씩 한국어 → 영어]
문장을 추출하면 한국어 버전도 자동으로 준비합니다.
「한글 보고 한 문장씩 말하기」 또는 카드의 「녹음하고 연습」을 누르세요.
처음부터 한국어 문장이 보이고 영어 답안은 가려져 있습니다.
한국어를 영어로 말하기 → 녹음 → 자가 점검 → 복습 저장 → 다음 문장.

[여러 문장으로 한글 문단]
각 카드에서 「문단에 활용」을 2~5개 선택합니다.
「여러 문장으로 한글 문단 연습」을 누르세요.
선택하지 않으면 학습한 문장부터 3개를 자동으로 고릅니다.
한국어 문단이 먼저 보입니다. 학습한 문장들을 활용해 영어로 이어 말하세요.
영어 예시는 「예시 답안 보기」 또는 음성 듣기로 확인합니다.
「다음 문장 묶음으로 문단 연습」으로 다른 문장도 계속 연습하세요.
표현 서재에서 여러 문장을 고른 뒤 「선택 표현 바로 연습」을 눌러도 됩니다.

[한국어 준비 — 처음 한 번]
지원되는 데스크톱 Chrome에서는 기기 내 번역으로 한국어를 만듭니다.
첫 사용에는 브라우저가 번역용 언어 파일을 다운로드할 수 있습니다.
번역 기능 연결이 실패하면 표시되는 「한국어 번역 다시 시도」를 눌러 주세요.
그 뒤 완료된 한국어는 학습 기록에 저장되어 다시 번역하지 않습니다.
브라우저 번역을 지원하지 않으면 준비된 무료 로컬 AI를 사용합니다.

[새로운 상황의 문단 — 무료 AI]
무료 AI 준비 안내 → Ollama 설치·실행 → 실행 상태 확인 → 무료 AI 준비.
API 키나 유료 호출 없이 동작합니다. 모델 다운로드는 약 3.4GB입니다.
AI가 준비되어 있으면 학습한 여러 문장으로 새로운 상황의 한글 문단을 만듭니다.
없거나 생성에 실패하면 학습 문장들의 한국어 내용을 이어 말하는 문단을 사용합니다.
화면에서 두 문단의 출처를 구분합니다. 한국어를 직접 작성할 필요는 없습니다.

[소리가 없으면]
문장 카드 위 「목소리 새로 읽기」와 목소리 선택을 확인하세요.
기기 음성 설정에서 음성 테스트를 할 수 있습니다.
Windows에 영어 음성이 없으면 영어 음성을 추가해야 합니다.
브라우저 온라인 음성은 카드 위 「온라인 영어 음성 사용」에서 직접 허용할 때만 사용합니다.

[실행]
Windows: start_youtube_windows.bat (Python 3.10~3.14, 최초 자막 패키지 설치)
macOS/Linux: bash start_youtube_mac_linux.sh
주소: http://127.0.0.1:8765/    종료: 실행 창에서 Ctrl+C
OPEN_ME.html에서도 기본 자료와 음성 읽기는 됩니다. 한국어·자막 기능은 로컬 실행 권장.
자동 자막이 차단되면 TXT/SRT/VTT나 스크립트를 가져오세요.
