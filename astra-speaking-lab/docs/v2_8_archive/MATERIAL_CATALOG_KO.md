## 연결과 상태

- 강의 캡처 19개, 연설문 Word 11개, KPOP PDF 2개, 인터뷰 PDF 2개: 원본 34개를 각 자료에 연결했습니다.
- 자료별 표현 열기: 이전 검색어와 핵심 필터를 초기화하고 해당 자료에만 한정합니다. 연설문 전체나 다른 영상이 섞이지 않습니다.
- 목록 탐색은 영어 예문 노출·연습 완료로 기록하지 않습니다. 연습한 항목 수는 실제 평가 기록으로 계산합니다.
- PDF는 선택했을 때만 학습 화면을 열며, 목록으로 돌아오면 검색·분류를 유지합니다.
- 저장 영상의 문장만 열 때는 다른 영상 자막을 바꾸거나 자막을 내려받지 않습니다.
- 자막·대본 열기는 기존 자막 불러오기 절차를 따릅니다. 다른 자막의 교체를 취소하면 기존 입력·화면을 유지합니다.
- 유료 API 없이 기본 교재의 문단 연습, 뜻을 보고 한 문장 만들기, PDF 한국어 말하기를 사용할 수 있습니다.

## 검증 범위

실제 데이터 3,297개 항목과 원본 34개를 목록에 대조했습니다. 검색·분류·기존 22개 자료 각각의 표현 연결·PDF 왕복·저장 영상 복원·영상 중복 방지·녹음 중 전환 차단을 검사했습니다. 기존 원본과 데이터 파일 5개는 v2.7.1과 바이트 단위로 같습니다.

자동 UI 검사는 jsdom 및 모의 음성·번역·자막 응답을 사용합니다. 실제 Chromium 설치 시도는 다운로드 시간 초과로 완료하지 못해 이번 버전의 실브라우저 화면과 Windows 음성 출력은 확인하지 못했습니다. 자막 본문을 새로 내려받거나 유료 API를 호출하지 않았습니다.
