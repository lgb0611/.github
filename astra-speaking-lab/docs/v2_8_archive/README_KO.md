# Astra Speaking Lab 2.8 — 전체 학습 자료 통합

학습 자료 탭에서 기존 25개 자료와 이 브라우저에 저장한 유튜브 자료를 모두 찾아 공부할 수 있습니다. 기본 자료의 3,297개 학습 항목과 원본 파일 34개를 그대로 포함합니다. 앱은 무료 모드로 시작합니다.

## 시작하기

1. 기존 실행 창을 종료하고 새 ZIP을 모두 압축 해제하세요.
2. 새 폴더의 `start_youtube_windows.bat`을 실행하세요.
3. 기존에 쓰던 브라우저와 같은 주소를 사용하세요. 기본 주소는 `http://127.0.0.1:8765/`입니다.
4. 상단 **학습 자료**에서 자료를 고르세요.

기존 학습 기록은 브라우저에 저장됩니다. 같은 주소·같은 브라우저 프로필을 쓰면 기존 기록과 저장한 유튜브 문장을 이용합니다. 주소나 브라우저를 바꾸려면 이전 앱의 설정에서 기록을 내보낸 뒤 새 앱에서 가져오세요.

인터넷 연결 없이 포함된 자료를 읽고 공부하려면 `OPEN_ME.html`을 Chrome 또는 Edge로 열어도 됩니다. 다만 이 방식의 저장 공간은 서버 주소로 실행할 때와 다를 수 있습니다. 녹음과 영상 자막 가져오기는 무료 실행기 사용을 권장합니다.

## 모든 자료 찾기

| 분류 | 기본 자료 수 | 학습 항목 |
|---|---:|---|
| 가브리엘 | 10강 | 핵심 표현 100개, 한글 문단 연습 70개 |
| 연설문 | 11개 | 단어·표현 2,554개, 원자료 인용 예문 |
| KPOP Demon Hunters | 1개 | 표현 220항목, 한글 문단 연습 2개, 표현집·대본 PDF |
| 인터뷰 PDF | 2개 | JENNIE 60개, Elon Musk 363개 문장·응답, 응용 문단 각 5개 |
| 유튜브 | 1개 + 직접 저장한 영상 | Arthur Brooks 영상 링크, 브라우저에 저장한 영상별 문장 |

- **전체 / 가브리엘 / 연설문 / KPOP / 인터뷰 PDF / 유튜브** 버튼에는 분류별 자료 수가 표시됩니다.
- 자료 제목, 인물 이름, 영어 표현, 한국어 뜻으로 검색하세요. 예: `가브리엘 8강`, `잡스`, `제니`, `confidence`.
- 각 자료의 **원본 자료**를 펼치면 강의 캡처·PDF·Word·영상 링크가 나옵니다. KPOP의 별도 대본 PDF도 포함합니다.
- **표현 보기 / 공부하기**는 해당 자료만 보여 줍니다. 왼쪽 자료 선택도 같은 분류와 목록을 사용합니다.
- 저장한 유튜브 문장은 영상 ID별로 묶습니다. 기본 영상과 같은 영상이면 한 항목으로 합치고, 자막 초안만 있어도 목록에 표시합니다.
- 자막이 없는 영상은 **자막 불러오기 필요**, 저장한 문장이 있으면 실제 문장 수를 표시합니다. 목록을 보기만 해서는 학습한 것으로 기록하지 않습니다.

자료별 전체 목록과 검증 범위는 `docs/MATERIAL_CATALOG_KO.md`에 있습니다.

## 자료별로 공부하기

**가브리엘 / KPOP:** `한글 문단으로 말하기`로 준비된 문제를 시작하거나, 해당 자료의 표현을 열어 한 개씩 연습하세요. 한국어 문제를 먼저 보여 주고 영어 예시는 가립니다.

**연설문:** `표현 N개 공부하기`로 그 연설문의 단어·표현·뜻을 확인하세요. `예문 듣기`는 원자료 인용 예문을 읽고, `뜻 보고 문장 말하기`는 그 뜻을 담은 문장을 직접 만들도록 합니다. 연설문 항목 수는 완성 문장 수가 아닙니다. 원본 해설 Word 파일도 함께 제공합니다.

**인터뷰 PDF:** `이 자료로 공부하기`로 문장 학습 화면을 엽니다. 영어 아래 한국어가 처음부터 나오며, 문장 듣기·대본 전체 재생·구간 반복·한글 보고 말하기·2~5개 선택 문단·응용 문단을 사용할 수 있습니다. `전체 학습 자료`로 돌아오면 검색 조건이 유지됩니다. 두 PDF의 한국어 423개와 응용 문단 10개는 미리 들어 있어 번역 연결이 필요 없습니다.

**유튜브:** 처음에는 `이 영상으로 학습 시작`으로 자막을 불러옵니다. 저장한 문장이 있으면 `저장한 문장 공부하기`로 바로 열고, `자막·대본 열기`로 전체 듣기와 추가 추출을 이어갈 수 있습니다. 현재 영상과 다른 자막으로 바꿀 때는 기존 자막 변경을 확인합니다. 저장한 문장만 공부할 때는 다른 영상의 자막 초안을 바꾸지 않습니다.

Arthur Brooks 영상은 제목·채널·길이·영어 자동 자막 트랙만 확인된 항목입니다. 이 ZIP에 새 영상의 대본·한국어 뜻이 미리 들어 있지는 않습니다. 실제 자막을 불러와야 학습 문장을 만들 수 있으며, 자막 본문을 가져오는 성공 여부는 사용자 PC의 네트워크와 영상 접근 상태에 달려 있습니다.

## 듣기와 복습

영어 듣기는 브라우저의 합성 음성을 사용합니다. 영어 음성이 없으면 `목소리 새로 읽기`를 누르거나 Windows에 영어 음성을 추가하세요. 온라인 음성만 있으면 화면에 표시된 **온라인 영어 음성 사용**을 직접 허용해야 재생할 수 있습니다.

말한 뒤 녹음이나 입력한 답변을 확인하고 자가 점검하여 복습 일정을 저장하세요. API 키 없이 공부할 수 있습니다. 새 영상의 한국어 뜻은 지원되는 브라우저 번역 또는 준비된 무료 로컬 AI를 사용하며 최초 설정·언어 파일 다운로드가 필요할 수 있습니다.

자동 검사 226건이 모두 통과했습니다. 자료 목록과 실제 데이터·원본 파일을 대조하고, 자료별 이동·검색·분류·저장한 영상 복원·기존 기능을 검사했습니다. 결과는 `docs/validation_results.json`과 `docs/catalog_node_test_results.txt`에 있습니다. UI 검사는 DOM과 음성 이벤트를 모의한 검사이며 실제 Windows 브라우저의 소리 출력 검사는 아닙니다. 유료 API는 호출하지 않았습니다.
