Astra Speaking Lab 2.9.0 — 유튜브 전체 문장 한 번에 추출

1. 기존 실행 창을 종료하고 새 ZIP을 모두 압축 해제하세요.
2. 새 폴더의 start_youtube_windows.bat을 실행하세요.
3. 기존 브라우저에서 같은 주소를 여세요. 기본: http://127.0.0.1:8765/
4. 상단 ‘학습 자료’에서 분류하거나 검색한 뒤 자료를 고르세요.

[이번 변경]
유튜브 듣고 말하기 → 링크 입력 → 이 영상으로 자동 학습 만들기
자막의 전체 문장을 마지막까지 한 번에 추출합니다.
‘한 묶음’ 개수 선택과 ‘다음 문장 추가’ 버튼이 없어졌습니다.
‘추출된 문장 더 보기’는 이미 추출한 문장을 화면에 더 보여주는 버튼입니다.
한국어 뜻은 전체 목록에서 순서대로 준비합니다.
기존 자료도 전체 자막 초안이 남아 있으면 나머지 문장을 자동으로 채웁니다.
기존 한국어 뜻과 복습 기록, 진행 중인 연습 순서는 유지합니다.

[기본 자료 26개]
가브리엘 10강 / 연설문 11개 / KPOP 1개 / 인터뷰 PDF 3개 / 유튜브 1개
전체 학습 항목 3,381개와 원본 파일 35개를 그대로 포함합니다.
이 브라우저에 직접 저장한 유튜브 문장·자막 초안은 영상별로 자동 표시합니다.

- 한글 문단으로 말하기: 해당 교재의 준비된 문제로 시작
- 표현 보기·공부하기: 선택한 자료의 표현만 표시
- 인터뷰 PDF: 한국어 뜻, 문장 듣기, 전체 재생, 구간 반복, 말하기
- 원본 자료: 강의 캡처·PDF·Word·영상 링크
- 저장한 문장 공부하기: 자막을 다시 받지 않고 저장된 문장 학습

같은 브라우저·주소에서는 기존 기록을 사용합니다.
브라우저나 주소를 바꿀 때는 이전 앱의 설정에서 기록을 내보내 새 앱으로 가져오세요.

Arthur Brooks 영상은 자막 불러오기가 필요한 링크 자료입니다.
영상 대본·한국어가 미리 포함된 상태는 아니며 인터넷과 무료 자막 실행기가 필요합니다.
영어 듣기는 브라우저 합성 음성을 사용합니다. 유료 API 키 없이 공부할 수 있습니다.
